This project is an optimized interactive fluid simulation written in C#, utilizing Godot spatial shaders and compute shaders. It will eventually be released as a GDExtension addon, tentatively named **IWS (Interactive Water System).** 

## Features

☑ Multiple Water Bodies Support in a Single Scene

☑ Physically-Based Optics (Surface, Underwater)  

☑ Voxel-Based Buoyancy Simulation  

☑ Finite Water Bodies (Pools, Lakes)

☑ General Disturbances (Point Impacts, Disc Pressure)

☑ Character Specific Disturbance

## Roadmap

☐ River Spline

☐ Ocean "Infinite Plane"

☐ Vehicle Specific Disturbance

☐ Water Exclusion  

☐ VFX Particle Spawning

☐ Audio

☐ Editor Usability Improvements

☐ C++/C Migration (GDExtension)  

## System Requirements

- Requires a GPU with **Vulkan support**.
- Built for the **Forward+** Renderer (Compute Shaders are heavily utilized)

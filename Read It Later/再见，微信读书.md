# 再见，微信读书

[![[Read It Later/attachments/ecdf8fc540d3a56270fffade3c542c89_MD5.png]]](https://www.zhihu.com/people/ma-qin)

[马小帅](https://www.zhihu.com/people/ma-qin)

今天聊聊读书软件，主要是最近新发现了一个好东西，深得我心。

不知道大家追小说的时候会不会遇到特别上头的时候，恨不得 24 小时逮着机会就看。

比如说，白天在办公室电脑摸鱼，看会小说；下班在路上开车的时候，手机无缝衔接进度，接着进度给我读；回到家里，躺床上掏出手机接着看。

简单说就是，走哪看哪，必须得接上。

你看，其实是个很简单的需求对吧，但是实现起来没那么简单。

在阅读软件这个领域里，绕不开两个存在：

一个是国民级的微信读书，书库确实牛，但脾气也大得很。你想让它朗读一下自己上传的书籍？不好意思，这项服务只对付费用户开放。

  

![[Read It Later/attachments/43e3d208f3a20033e411ca9d067b5bd5_MD5.jpg]]

  

另一个是开源的阅读 App，自由是真自由，书源一导，啥都能看，但问题是它只支持 Android 系统，苹果手机无法使用，而且同步进度还需要折腾 WebDAV 服务，有点麻烦。

我的需求真不高，就是想安安静静、不被打断地看/听我自己的书，不管是在手机和电脑屏幕前，还是在方向盘后。

说实话，为了这事我折腾了好久，直到最近在知乎上看到了 [Readest](https://zhida.zhihu.com/search?content_id=264290911&content_type=Article&match_order=1&q=Readest&zhida_source=entity) 这个阅读工具。它没搞什么花里胡哨的功能，但就是把「阅读」这件最核心的事，打磨得异常舒服。

官网：[https://readest.com/](https://link.zhihu.com/?target=https%3A//readest.com/)

[https://github.com/readest/readest](https://link.zhihu.com/?target=https%3A//github.com/readest/readest)

  

![[Read It Later/attachments/0287c193e73840d0ccdca2ec9cb23897_MD5.png]]

  

我浅用了几天，非常 nice，就想给和我有同样烦恼的小伙伴们，分享一下这个终极解决方案。

全平台同步

Readest 最让我眼前一亮的功能，就是它完美解决了上面那个让我头疼的场景。

作为一款开源工具，它深刻理解现代人的多设备、多场景生活，因此支持全部客户端以及网页，可以满足你在各种设备上的阅读需求。

  

![[Read It Later/attachments/d37b049b7fba9a8d33ed6ee5457c9b86_MD5.png]]

  

  

账号默认提供 500M 的云端存储空间，登陆即可支持多端同步电子书、阅读进度、划线和笔记。

它的同步功能做得极其扎实。你在电脑上看到哪一页，打开手机就是哪一页，几乎没有延迟。这玩意听起来是基础功能，但能做得这么无感的真不多。

  

![[Read It Later/attachments/8d85ace893876ffdbb850af6a55022bc_MD5.png]]

  

电脑端进度

  

![[Read It Later/attachments/c6740727c3d0a592821cf59e5e34ba21_MD5.jpg]]

  

手机端进度

  

这就意味着，前边提到的不管是办公室的电脑还是手机上看书或者听书，整个过程都能无缝衔接，那种进度在不同设备间顺畅流动的感觉，体验感直接拉满。

单凭这一点，它就秒杀了市面上绝大多数阅读软件。

  

纯粹的阅读环境

第一次打开 Readest，你可能会觉得它有点简单得过分。

没有社区，没有排行榜，主界面就是你的书架。在这个恨不得把所有功能都塞给你的时代，这种干净简直是一股清流。

  

![[Read It Later/attachments/2bf06b0604444906d87df816ce2924db_MD5.png]]

  

但当你真正开始用它读书，你才会发现它的好：

高度自由的排版，黑白模式自然不必说，它还内置了好几种很舒服的主题配色。

  

![[Read It Later/attachments/71ec483011e2ab5d77e36556a7de2092_MD5.jpg]]

  

当然，你也可以像搭积木一样，自己定义字体以及大小、行间距、段间距，几分钟就能调出一个最适合你眼睛的专属模式 。

  

![[Read It Later/attachments/92931e07c5eba237e161a3f440aad481_MD5.jpg]]

  

它还有一个「沉浸模式」，能把顶部的状态栏都给你隐藏掉，让整个屏幕变成一张纯粹的书页 。

你看不到任何多余的按钮来分散你的注意力，这就是极致的沉浸感。

  

![[Read It Later/attachments/287509840e1c5f1ab8f086b6281ddbbd_MD5.jpg]]

  

它似乎在用所有的细节告诉你：别想别的，好好看书。

  

丰富的阅读功能

  

Readest 它不提供任何书源，但是几乎支持所有的格式书籍，不管你是 ePub、MOBI、azw3 还是 PDF、TXT，直接拖进来就能看，省去了转换格式的麻烦。

  

![[Read It Later/attachments/910ad14ddd15398344d20536902058e1_MD5.png]]

  

  

最关键的是，它支持朗读你导入的书籍，它支持 [Edge TTS](https://zhida.zhihu.com/search?content_id=264290911&content_type=Article&match_order=1&q=Edge+TTS&zhida_source=entity) 无限朗读书籍，可以随时切换不同音色。

之前给大家介绍过很多次，这种 AI 语音拿来朗读书籍效果最自然的，而且免费。

  

![[Read It Later/attachments/91c15ce228000ca930ff354365081128_MD5.jpg]]

  

有时阅读外文时不可避免的会用到翻译，那翻译质量最高的莫过于 [DeepL](https://zhida.zhihu.com/search?content_id=264290911&content_type=Article&match_order=1&q=DeepL&zhida_source=entity) 了，而Readest 的翻译功能就是基于 DeepL 引擎，当然你也可以选择其它引擎。

  

![[Read It Later/attachments/c811ed25e9f5c4d6def448fb3d902c3a_MD5.png]]

  

还有个亮点是 Readest 还有一个平行阅读功能，可以同时阅读两本书，点击右上角的回形方框，然后选择两本书打开。

  

![[Read It Later/attachments/7cb3276a4c6f760229ba01b7cd3d54e5_MD5.png]]

  

在阅读界面上方也可以进入这个功能。

![[Read It Later/attachments/53279a5bd1b4d185f5c3ee19aaa2a29a_MD5.png]]

  

这种能够同时阅读两本书或文档的功能，在需要对比中英文书籍时非常有用。

  

![[Read It Later/attachments/90f783ada35d5411cbeaa31c4ae847f6_MD5.webp]]

  

如果说前面的体验让我觉得好用，那它的笔记系统则让我觉得必须拥有。

很多软件的笔记功能，说白了就是把你套牢的工具。你在里面做的笔记越多，就越离不开它，你的知识成了平台的人质，微信读书就是个典型例子。

Readest 的思路完全相反，它认为你的思考，永远属于你自己。

在 Readest 里，你可以方便地划线、批注。

  

![[Read It Later/attachments/84c855541b83dbf21c075ed359632ad6_MD5.png]]

  

所有摘录和笔记都会被自动整理到笔记中心，方便你随时回顾和搜索 。

  

![[Read It Later/attachments/83e9a0ab5ee1b3f9ad016d8cef1ef749_MD5.png]]

  

最牛的是，它支持一键将你所有的笔记和划线，导出为通用的 Markdown 格式。

这意味着什么？意味着你多年积累的读书笔记，可以轻松导入到 [Notion](https://zhida.zhihu.com/search?content_id=264290911&content_type=Article&match_order=1&q=Notion&zhida_source=entity)、[Obsidian](https://zhida.zhihu.com/search?content_id=264290911&content_type=Article&match_order=1&q=Obsidian&zhida_source=entity) 等任何知识管理工具里，真正构建成你自己的知识体系。这才是真正意义上的知识私有化，你的思考不再被任何平台绑定。

这背后是对书这一知识资产最原始的尊重——它属于你，也只属于你。

结语

总的来说，Readest 不是那种想方设法吸引你注意力的 App。它更像一个可靠、专业的书房管家，不打扰，不炫技，在你需要的时候，永远提供最舒适的服务。

它解决了微信读书不自由和开源阅读不同步的核心痛点，尤其是在朗读私有书籍和同步阅读进度这两点上，做到了无可替代。

说句心里话，在微信读书和各种开源阅读已经拥有如此庞大用户基础的今天，还能看到 Readest 这样的新竞品出现，并且凭借扎实的体验收获了一片好评，我个人是乐见其成的。

这就说明，依然还有一些核心的需求没有被现有巨头完美解决，而这些未被满足的需求，就是机会所在。

很久没有给大家分享好用的软件了，但今天这个的确是近来让我爱不释手的新欢，必须得让你们也知道。

# 老外们的“戒色吧”有多魔怔？！

在我的认知中，戒色吧老哥这类人群本应是中国文化下的独特产物。

流传千年的中医理论和国内人尽皆知的[色即是空](https://zhida.zhihu.com/search?content_id=225430731&content_type=Article&match_order=1&q=%E8%89%B2%E5%8D%B3%E6%98%AF%E7%A9%BA&zhida_source=entity)思想，并称为戒色老哥们的两大理论武器，因此即便科技发展到了今天这个地步，戒色论仍然能靠这两位大哥的影响力收割一批坚定的支持者。不过这套说辞照搬到国外就失去了文化根基，按理说掀不起什么风浪才对。

![[Read It Later/attachments/2246ba0774b35f6ce4237e8bb865514a_MD5.png]]

然而推特、TIKTOK等国外社交媒体上，一个个声色俱厉地讲述传统手艺的危害的老哥老姐证明我错了——哪怕在国外，不许涩涩的保守势力也相当强大。

![[Read It Later/attachments/67b8a5993ead77a203b94b5229c7af88_MD5.png]]

## **论戒色，还是老外更魔怔**

与渗透着几千年玄学研究的国内戒色学派相比，老外的反涩涩宣传就显得很单薄、肤浅，他们的戒色学说缺乏中医那样系统性的理论支持，只不过是在机械地重复导管会削弱男性能量、流失生命力之类的片汤话。

![[Read It Later/attachments/4c61c705ab6c9a5c38b5175af979afdc_MD5.png]]

更恶劣的还会把狗骗进来杀，先用美女勾引你点进来，再站在道德高地上谴责你想要涩涩的思想有多么龌龊。

![[Read It Later/attachments/548f99917604267079d53f24f01bf1db_MD5.jpg]]

“你可真是个废物，竟然对着屏幕里的一团像素点打胶，而这个女人甚至不知道你的存在……”

狂热的戒色主义者整天念叨什么，在国内戒色吧逛过的朋友大抵也都能猜到，无非就是宣扬“传统手艺等于慢性自杀”“禁欲的人更受异性欢迎”之类的反智言论，而不少博主对涩涩的斗争和批判都殊途同归地落到了卖课上，干起了收智商税的买卖。

![[Read It Later/attachments/9ee72b04f5e3914c24d57ec75a321064_MD5.png]]

不过相比于那些只想着谋财的骗子，那些真把戒色当成正义的魔怔人更加危险。

[No Nut November](https://zhida.zhihu.com/search?content_id=225430731&content_type=Article&match_order=1&q=No+Nut+November&zhida_source=entity)（缩写NNN）本来只是让老哥们禁欲一个月养精蓄锐，提高夜生活质量的活动，却在一群戒色魔怔人的参与下成为了众矢之的。几年前，充满极端思想的魔怔人在NNN活动大肆散播“爱情动作片是犹太人要腐化男人”的阴谋论，更有甚者还直接开始对制作爱情动作片的作者散布死亡威胁。

![[Read It Later/attachments/a29b4fd66bc4a6fda5779bc9340e08cb_MD5.png]]

国外这些戒色魔怔人的死亡威胁，可不只是说说而已。

事实上，许多在政治、宗教上非常极端的团体都对这类不许涩涩的主张青睐有加，比如一个自称为incel（非自愿独身）的团体就是戒色主义的忠实拥趸，这些人是往往是社会边缘人群，因为仇恨女性而在网上抱团取暖，在欧美各国制造了许多针对女性的血腥枪击案。

因此在一系列骇人听闻的恶性事件之后，戒色老哥们就顺理成章地被认为是孕育极端思想的温床。在媒体口中，仇恨女性的极端派和反科学的阴谋论者在这里作妖斗法，批量制造蠢蠢欲动的反社会分子。

![[Read It Later/attachments/4f801e20fd126b92309ad8215324bc19_MD5.png]]

然而在我抱着看乐子的猎奇心态进入国外戒色吧的时候，却发现这里并不像媒体所说的那么单纯。

## **国外戒色吧什么样**

“No Fap”是外网上最大的戒色论坛，并且从某种程度上说，它的创立与中国脱不了关系。

十多年前，一位名为亚历山大·罗德斯的年轻人在为自己的一事无成而忧郁。起初他并没有将自己的不得志和长达十几年的大魔导师资历联系在一起，但偶然间他看到了一篇来自中国的论文，发现在禁欲一周后，男人的睾酮水平会有所上升，对身体有着一系列影响。

![[Read It Later/attachments/d94fe255806091b0169c70d899a7a736_MD5.png]]

在这篇文章的点化之下，他悟了，一个想法在他的脑海里逐渐形成——如果停下传统手艺，生活是否会有所变化。

本着大胆假设小心求证的研究态度，他创立了[No Fap论坛](https://zhida.zhihu.com/search?content_id=225430731&content_type=Article&match_order=1&q=No+Fap%E8%AE%BA%E5%9D%9B&zhida_source=entity)。所谓“Fap”，是国外不正经漫画里用来模仿男人传统手艺的拟声词。顾名思义，No Fap是一个方便大家交流戒导经验的地方。

![[Read It Later/attachments/64e798eb0752f1dbcaee7e5da4c0c6d2_MD5.png]]

经过上百万戒色老哥十多年的探索，如今的No Fap已经形成了一套成熟、系统化的戒导流程，分为简单、标准和困难三个难度任你挑战。

简单模式中，你不需要做到真正意义上的戒色，只需要开启互联网的青少年模式、封印硬盘里的学习资料，在与网络涩图、爱情动作片完全隔离的前提下，你仍然可以手冲或与人共赴巫山云雨——只是对于那些老婆就在屏幕里的LSP而言，这其实已经与不许涩涩画等号了。

![[Read It Later/attachments/65033e0d86ddd06c39f69db7bc18d682_MD5.png]]

而标准模式才是我们通常理解的戒色：禁止传统手艺和各种涩涩内容，奖励自己的唯一方式是线下找人激情battle，这也是三种模式中最受欢迎的一个。

困难模式则是完全禁欲，让人彻底过上无欲无求的出家生活，据说这种模式的效果最好，毕竟只要隔绝一切邪念遁入空门，自然就会明白肉体凡胎皆是酒肉皮囊，哪有什么男女之别。

![[Read It Later/attachments/c22b73b0bdef808ef425ae269571f742_MD5.png]]

一般来说，按照这套戒导流程执行90天以后，你就会感受到自己的生活有了明显的变化，那些经历过90天试炼的网友还反映自己减少焦虑、更加自信、自律，甚至更受异性欢迎了——至少他们自己是这么认为的。

而在他们标榜种种好处中，唯一经过科学证明的就是腾出了每天找片看所占用的时间。

这群人除了对戒色的狂热有点邪门之外，No Fap论坛并不像媒体口中那样充满仇恨和反智言论，反而呈现出一种诡异的和谐，当代互联网嘴臭与戾气仿佛并不存在，这里的每个人都在为了彼此的戒色大业相互鼓励，看上去非常不真实。

在这个国外版的戒色吧里，最常见的内容是展示自己的戒色成果，如同日常打卡一般记录一下自己的自律天数，以便大家相互督促。有些人还会展示一些自己在与心魔搏斗时为了转移注意力而绘制的画作或者健身前后的腱子肉，这些帖子下面往往是清一色的赞美和鼓励。

![[Read It Later/attachments/680cd3a2e8d4db9688cb22b404caf4b9_MD5.png]]

另外还有不少戒色失败后到社区寻求心理疏导和安慰的老哥，而平日里充满戾气的互联网在这个角落展示出了温柔的一面，许多人都会无条件地给这些没能坚持到最后的人加油打气。联想到这里九成以上都是男性，这种相亲相爱的氛围就显得更加诡异了。

![[Read It Later/attachments/a76b99dcce7d9cccc347bd1f1691c9f2_MD5.png]]

不过风平浪静的水面之下往往是暗流涌动，No Fap论坛也是如此。在这里，现身说法讲述自己沉湎于涩涩后有多么痛心疾首很容易引起共鸣，而那些有极端倾向的戒色原教旨主义者就会借此抬头，大谈No Fap论坛已经违背了自己的初心，完全无视了为欲望所苦的吧友们身心上受到的折磨，只会拿几句专家的话强调传统手艺的无害性，太过迷信科学权威，真正的戒色人已经不应该留在这里了。

另一方面，面对这些反智思想的抬头，那些迷信科学的网友也坐不住了，对论坛里流传的各种流言蜚语正面硬钢，例如论坛里有段时间传统手艺与前列腺癌有关的传言实在太过频繁，一位医生吧友不得已亲自下场开团辟谣，怒喷大伙对这些反复出现的谣言没有判断力。

![[Read It Later/attachments/5a398e3f2381b834c17639f6ab65c1f6_MD5.png]]

这些不时打破平静的不稳定因素都说明，在媒体上处于争议漩涡中的No Fap论坛的确不像它表面上那么平静，虽然有些极端分子在蠢蠢欲动，但大多数还算是正常人，哪怕看起来不太聪明。

不过如果不是被谣言蛊惑，那这群人为什么要戒色呢？

## **回归初心**

不知各位在上网冲浪的时候有没有这样的感受：自己对小兄弟的掌控力越来越弱了。

在无论你看的是社交媒体、视频网站还是电影游戏，勾人欲火的性感女郎已经渗透进了互联网的每个角落，总有一个能说服你在夜深人静的时候奖励自己一把。

![[Read It Later/attachments/f50983b411d071a80efb09b6e153e46a_MD5.png]]

在如今这个信息爆炸的时代，各种涩涩的内容冲击着我们的感官，不仅是广大LSP们搞传统手艺的电子榨菜，更融入了注意力经济为代表的网络商业模式，现在美女已经成为了短时间引起你注意力的最优解，只要你不是网络绝缘体，想必就亲身体验过这个套路的威力。表面上它们针对的是下半身，实际上瞄准的还是你的钱袋子。

![[Read It Later/attachments/f983a657c79acccd71ee966c982b759c_MD5.png]]

对互联网涩涩现状进行充分反思之后，No Fap的网友们发现了人类的鸡儿已经被互联网所绑架的事实。而在这种饱和式涩涩的冲击下，大家对涩图的要求越来越高，觉醒的XP越来越猎奇，追求的视觉冲击力越来越强。经过互联网涩图经年累月的高强度训练，许多人对现实中的异性已经是性趣寥寥，甚至与同自己的伴侣真刀真枪地实战相比，可能对着网络涩图玩传统手艺的快感更强烈。

![[Read It Later/attachments/98588e20f5c384a0e81cc6173d6069b8_MD5.png]]

在饱经网络涩图摧残后，No Fap的老哥们从自己的个人经历中归纳出了一条血的教训：涩涩就和抽烟喝酒一样，是会让人上瘾的。

乍一看这个结论似乎很符合常识，但实际上也是一种民科，科学家们对于涩涩成瘾的态度一直比较模糊，它究竟是否应该和烟草、酒精一样被归为成瘾物仍尚存争议。而鉴于手冲也不会明显影响健康，医疗领域的权威机构一直秉持着大家就爱咋地咋地的放任态度。

但No Fap里汇集的那些为涩涩所苦的老哥却不这样想，亲身体会的教训告诉他们，如果再不做点什么，自己就要被鸡儿夺舍了。

![[Read It Later/attachments/40b1b698cdf5e89ed8019b77c213bad6_MD5.png]]

No Fap的老哥们率先向涩涩宣战的行为，不仅是为了夺回自己身体的主导权，甚至可以说是对当今大资本大公司利用人性弱点大发横财的控诉与反叛。

在这种朋克精神的感召下，我也深受鼓舞，决定从今天开始告别传统手艺，跟那些用互联网腐蚀大众的资本家奋战到底。

正当我想要发个朋友圈明志时，随便划拉了两下手机，无意间点进了某个技术交流群，一张张赏心悦目的美图吸引了我的目光。

算了，要不明天再说吧。

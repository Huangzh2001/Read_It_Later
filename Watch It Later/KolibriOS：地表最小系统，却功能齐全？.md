[章节] 前言

随着操作系统的功能越来越多，现在的操作系统的系统镜像大小越来越大，达到了好几 GB，但是在现在镜像大小不断膨胀的时代，有一个系统，大小仅有 1.4 MB，足以在一张 3.5 英寸的软盘中安装，但是预装了丰富的内置软件，这个系统就是 KolibriOS，我们今天就来开箱体验一下这个系统，看看这个系统有些什么功能，有些什么用途，首先来介绍一下 KolibriOS。

[章节] KolibriOS 介绍

Kolibri 这个词来源于俄语（一说哈萨克语、斯拉夫语）的 Колибри（蜂鸟）这个词，这个系统发源于 MenuetOS，后来在 2004 年从 MenuetOS 中分叉开来独立开发，MenuetOS 有 32 位和 64 位版本，在 KolibriOS 项目启动后不久，MenuetOS 的开发者就决定只专注于 64 位版本，与其 32 位版本不同，它是闭源的，而 KolibriOS 只有 32 位版本且一直保持开源，KolibriOS 最初以俄语区开发者为主，现在该项目已拥有多国开发者，它体积很小，软盘映像只有 1.4 MB，而光盘映像只有 90 多 MB，并且采用汇编语言编写，不依赖任何 Linux 或 Windows 系统内核，所以该系统在很多设备上只需几秒钟即可启动，打开程序也几乎是瞬时打开，KolibriOS 需要 i586（Pentium）及以上的 x86 处理器，至少 12 MB 的 RAM，VESA 或 VGA 的标准显卡即可运行，那么下面我们就开始下载体验这个系统。

[章节] KolibriOS 装机体验

这个系统可以从它的官网下载到，目前这个系统还在持续更新，这个系统有英文版、俄文版和西班牙文版，有软盘、光盘和 UEFI/BIOS 混合镜像，其中 UEFI/BIOS 混合镜像需要安装到 U 盘中运行，其余两个映像只能安装在相应介质中并在 BIOS 固件的电脑中使用，我这里下载了一个软盘映像，它的大小只有 1.4 MB，为了保证较好的使用体验，建议使用 VirtualBox 或 QEMU 体验该系统，在 VirtualBox 中挂载该软盘映像，然后启动系统，可以看到启动系统的速度非常快，几乎只用了不到 1 秒，进入系统后，我们打开软件，几乎都是秒开，没有一点卡顿，下方是菜单栏，左侧两个按钮分别是菜单键和全部最小化按键，右侧三个按钮分别是输入法、CPU 使用率和时间，输入法只有英文和俄文输入法，点开时间按钮，可以查看日历和设置时间，可以看到系统中预装了很多软件，我们来看看有些什么软件，这个系统中内置了三种文件管理器，分别是 KFM2、Eolite 和 KFAR，KFAR 的样式看起来很像 DOS 系统的样式，KFM2 使用的是双窗口样式，Eolite 使用的是单窗口样式，对于开发者而言，这个系统内置了很多开发者调试工具和代码编辑工具，例如，你可以使用 TINYPAD 或 CEDIT 编写代码，系统内置了一个汇编语言代码示例脚本，你可以用它学习汇编语言，便于你学习如何操作硬件。

输入完成后可以运行这个程序，当然，这个系统也是支持 C、Oberon 和 Pascal 等编程语言的，系统还内置了一个汇编器，可以用它编译和调试程序，这个系统还内置了很多日常工具，例如计算器，绘图工具，测色计，图片查看器，音频播放器，不过可能因为声卡兼容性原因，没有声音，字符查看器，时钟和计时器，浏览器，不过这个浏览器内核比较老了，很多的网页都无法正确加载，系统设置，可以查询硬盘、CPU、PCI 等硬件的信息，不过这个系统最有趣的地方在于它内置的众多上古游戏，例如俄罗斯方块，管道游戏，贪吃蛇，乒乓球，恐龙奔跑，这个游戏我不知道其名字，有知道的可以在弹幕中打出来，消消乐，数独，数字华容道，五子棋，记忆游戏，这个系统还有很多功能，限于篇幅，我就不一一演示了，大家可以自行下载系统镜像体验。

[章节] 总结

总结一下，这个系统虽小，但是功能非常全，涵盖了日常工具、开发、文件管理、硬件信息查询、娱乐等众多需求，它的用途非常广泛，可以学习底层汇编，复活老旧电脑和低配工控机，还可以用作应急 Live 系统快速浏览和备份硬盘文件，当然也可以在虚拟机中趣味体验，但是缺点也是很明显的，它的软件生态非常薄弱，无法运行 Windows 和 Linux 程序，并且无法兼容现代网页，浏览器无法实现日常上网，所以无法用作普通用户的主力系统，那么，大家是否用过这个系统呢。

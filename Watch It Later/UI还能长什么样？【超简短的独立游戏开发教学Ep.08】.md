你好，我是N，欢迎来到超级短的独立游戏开发教学，今天我要带你深入了解，那个你也许已经很熟悉了的UI，UI全称user interface及用户接口，指的是程序提供给用户的，用于向程序下达指令的入口，在DOS系统的年代，UI是以文本命令的形式存在的，称为text based user interface，用户需要在命令行中输入特定的词语，来执行程序中的某些功能，但这种UI需要用户记忆大量的命令，而且不同的应用程序命令也各不相同，这无疑是非常不方便的，后来随着图形化界面的流行，基于图形的graphical user interface成为了主流，在屏幕这个二维平面上，一个个矩形按钮，通过直观的文字和图标，将使用接口和数据呈现暴露出来，让用户几乎不需要什么学习成本，就能掌握软件的基本使用，现代游戏中的UI正是借用自传统软件的GUI，但是由于游戏的特殊性，游戏UI并不能完全照搬传统软件的布局，甚至在表现形式上有时都与传统UI截然不同，那么让我们从以下三个切入点，来思考今天的问题吧，UI还能长什么样，透过现象看本质，对于绝大部分游戏画面的中央，是游戏的主体内容展示区，所以一些功能性UI，就只能围绕着中央的主画面进行排布，但有一些重要信息需要专门展示时，在中央弹出窗口或者覆盖整个屏幕，这是目前最成熟也最稳妥的方式，从独立游戏到手游再到顶尖大作。

都或多或少的遵循这种布局，你当然也可以标新立异的设计一些奇特的布局，不过如果你没有自信，能让玩家非常自然地接受你的布局，那么还是不要轻易尝试改变大多数人的习惯，除非你的游戏本身就非常特殊，在这个框架之下，你需要注意的是对UI摆放的取舍，对于模块比较繁杂的游戏，有人会喜欢把各个自己引以为傲的，经过精心设计的系统炫耀似的，一股脑放在主页的UI布局上，最终变成这种布局，为了解释这些系统，又需要制作一大堆的文本来说明，相信我玩家根本记不住，你要做的是对这些UI入口进行合并，让主页面尽可能的简洁，对于各个入口也可以一开始隐藏，在适当的时机展示出来，并加以说明，之后，还需要通过不断的引导，玩家去使用这个模块来加深记忆，然后再开启新的模块，对于如何循序渐进的进行引导，以后有机会我也会做一些分享，关于合并UI只需要遵循一条原则，就是越是高频使用的功能，玩家点开所需要的部署就要越少，合并UI也不要制作的过于繁杂，每个按钮都能点开子菜单，每个子菜单又能点开孙菜单，玩家会被逼疯的，你不必把所有UI入口都压缩在一起，然后放在主页布局上，可以把部分功能分配给NPC，店铺道具之类的角色，只把核心功能放在玩家触手可及的地方就好啦，另外由于各平台的操作差异，UI的布局也会有一些差别。

你需要根据游戏的发布平台来进行考量，手机的触屏既用于输入，也用于输出的特性，决定了大部分功能是必须摆在明面上的，而且要占据足够的面积来保证点击区域，而PC和主机因为键盘手柄的优势，很多功能入口只需要简单标示一下快捷键，无需设计庞大的图标，甚至一些约定俗称的按键，连标识都不需要，比如键盘上的escape键，手柄上的start键等等，接着我们来说一说UI的样式，为了匹配游戏的整体画风，很多设计师都会对UI进行一些风格化处理，比如CYBER风格，中世纪风格等等，如果你也想让你的UI个性一些，在隐形原生的UI样式基础上，可以适当更改颜色，边框形状等等，有时候根据功能对于页面的外框填充，这类东西可以进行适当加工，来表示这个UI模块与功能的联系，比如旷野之息里的希卡石板，动物，森友会里的智能手机晶体管理的操作终端等等，但是除非你是资深的UI设计师，否则不要过于放飞自我，制作太过个性的UI，一个按钮如果长得不像按钮，很容易造成混淆，令玩家对功能产生困惑，切不可舍本逐末，没什么设计灵感的时候，不搞花里胡哨，单纯让风格统一也是一个不错的选择，上面说的这些UI是直接对标于unity的GOUI模块的，不过既然UI的本质是提供给用户，操纵某个功能的入口，以及对某些信息的展示，那么其实你也不必拘泥于使用，贴在屏幕上的这些扁平的图像。

很多独立游戏其实没有什么文本，一些简单的提示信息和触发区域，你大可以试着做到游戏场景里去，给玩家一种打破次元壁的感觉，另外其实unity的UI也是可以放置到游戏场景里的，最常见的应用是NPC和怪物头顶的名字和血条，不过你也可以结合道具，将一些UI面板放到三维空间里去，比如科幻风格的游戏中，智能腕表或者AR眼镜，亦或是战舰的操作窗口，在道具激活时使用这种UI模拟全息投影的效果，或者简单粗暴一点，不做什么艺术加工，类似无主之地里，这种将新西兰放在角色面前的形式也很有趣，对于一些轻量化的游戏，也可以试着使用一些非图文的形式来呈现信息，比如之前我们进行头脑风暴的那个小游戏，你可以在九宫格旁边放置一些小方块，来展示玩家当前的关卡进度，之前的按键提示也可以做成模型放在场景里，总之无论如何，抓住UI的本质来进行设计规划，也许会比基于惯性思维设计出来的界面，更令人印象深刻，好了我们说了整整一期画面上的东西，也是时候来了点听觉上的玩意儿，下期视频我将从头开始，带你入门乐理，让你具备最基本的BGM写作能力。

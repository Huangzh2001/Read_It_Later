# 前言

由于abs键帽的耐磨性不如pbt，很多小伙伴的abs键帽用了一段时间就会出现打油的现象。大部分情况下只有常用的区域打油其他区域使用较少并未打油，造成整体观感不统一。本人轻度强迫症感到难以接受，突发奇想打磨一下键帽。因此写了这篇文章，只希望能帮助各位小伙伴们抛砖引玉。

![[Read It Later/attachments/82c7a57258818bc119bca9fb24f277fc_MD5.webp]]

翻阅了一些帖子，发现键帽现在主流的打磨方式分为两种（如不全可以更正哈）——物理方法和化学方法。顾名思义，物理方法即通过摩擦以达到打磨抛光效果，如砂纸，打磨膏，羊毛抛光轮等。化学方法通过ipa（异丙醇）这样的有机溶剂溶解腐蚀abs表面达到抛光效果。但是据百度百科说明，使用强酸生产异丙醇在一类致癌物清单中、异丙醇在3类致癌物清单中。考虑家里有小孩子，本文中并没有测试化学法，可能以后条件允许的时候会另开一篇文章补充化学法效果。

  

![[Read It Later/attachments/ad892f7c9521f6ecad0cdc52b110254d_MD5.webp]]

  

本次测试主要采用的工具如下，鹰牌2000目砂纸，鹰斧3000目砂纸，鹰斧5000目砂纸，鹰斧7000目砂纸，8000目钻石膏，小型羊毛抛光轮。

# 手动打磨

手动打磨时候要注意，打磨的时候不要太过用力，否则容易留下大的划痕影响观感。水砂纸可以沾水或者用细流水冲洗进行打磨，可以带走打磨时候产生的小碎屑。打磨方向我一般习惯8字或者画圈打磨，打磨痕迹比一个方向要均匀一些。打磨的时注意细心多观察表面。更多细节可以自己摸索或者查阅一下高达模型制作的打磨篇，在此不多赘述。

![[Read It Later/attachments/5379e4914e553314c2b5276797b8f54c_MD5.webp]]

对比一下不同目数砂纸打磨后的键帽效果。由于拍摄手机有些陈旧，效果一般还请担待。拍摄时候均采用同位置，同外部光线。拍摄时间跨度大概1分钟。虽然固定的曝光度，但是后面高目数的还是看着暗一些。

# 电动打磨器

电动打磨的主要工具是电动打磨器+羊毛抛光轮。在使用电动打磨器的时候一定要注意转速不能过高。心急吃不了热豆腐，转速过高可能会导致键帽变形哦，切记切记！如图中的键帽，惨不忍睹。

![[Read It Later/attachments/97232b119d8e153339475931e437017d_MD5.webp]]

转速过高

除了上面的问题，对于内凹的地方，电动打磨器的羊毛抛光轮相比手动砂纸就显得不够灵活了，很打磨起来比较费劲。在进行键帽五面抛光时，可以用来辅助打磨除顶面外的其余四面，其余四面为外凸弧线，相对与顶面的内凹容易很多。

# 总结

个人推荐新手打磨时候还是首选砂纸+打磨膏，相对来说容易控制。当然，用如果能熟练运用电动打磨器，打磨效率还是能显著提升的，至少手指头不会特别疼，抛光效果也不错。键帽打磨抛光一定程度上讲是提升了观赏性，降低了实用性。打磨抛光后的键帽容易沾染指纹和其他一些细小灰尘，出汗的时候使用还会有点粘手，整体打字体验个人觉得不如原来。当然，如果作为观赏摆拍，做个3d相框小摆件是挺不错的。各位小伙伴还要根据自己需要选择最适合自己的。

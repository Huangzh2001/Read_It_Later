今天给大家分享两款EDC好物，既有好玩的，也有学习、防身二合一硬货。它们就是来自FEGVE费戈出品的PEI版萝卜刀（兼开瓶器）以及新版的钛合金直尺“[钛空尺](https://zhida.zhihu.com/search?content_id=654795711&content_type=Answer&match_order=1&q=%E9%92%9B%E7%A9%BA%E5%B0%BA&zhida_source=entity)”。先来介绍个熟悉的：[PEI萝卜刀](https://zhida.zhihu.com/search?content_id=654795711&content_type=Answer&match_order=1&q=PEI%E8%90%9D%E5%8D%9C%E5%88%80&zhida_source=entity)。近年来，解压玩具花活层出不穷，除了早先的指尖陀螺外，推推牌、啪啪币，乃至萝卜刀先后大火。而费戈自主专利设计的萝卜刀更是一口气推出了多个版本。这其中就有早就一售而空的钛合金原色，还有后来只售三百多的铝合金“平民款”。此外还有两款限量，一个号称“灵龟战甲”，全身五彩加持，甚为漂亮。另个就是我手上这款采用PEI（即[聚醚酰亚胺](https://zhida.zhihu.com/search?content_id=654795711&content_type=Answer&match_order=1&q=%E8%81%9A%E9%86%9A%E9%85%B0%E4%BA%9A%E8%83%BA&zhida_source=entity)）材质的版本，它的透光性很好，橙黄外衣下也更引人注目。下面就让我们来了解下吧：

  

![[Read It Later/attachments/b62a6faebeff1eb6e6f0b00254605520_MD5.jpg]]

  

包装盒就不再赘述啦，依旧是FEGVE家的防水收纳盒。相比纸质更环保、实用。而内容物方面，除了本体外，还额外附送有螺丝批头一枚。

  

![[Read It Later/attachments/b029c9459f06de8dc561d9810cda91ef_MD5.jpg]]

  

这款PEI版更为稀有，全球只有13把。相较于钛版和铝合金版本，虽然结构设计相同，但它把玩起来更像是玩具。首先，它是目前所有发布版本中重量最轻的，仅为17克（钛彩版为53克，相对轻盈的铝合金版也有38克）。一半儿不到的重量让你在长久把玩时感觉不到疲累感。其次，CNC精雕细琢、数控表面抛光下的机身手感也是极好的，其温润如玉，剔透如黄晶，颇具潮玩属性。

  

![[Read It Later/attachments/cff06f26df697c98c78b1c780a49244e_MD5.jpg]]

  

塑料大家都知道，小朋友们玩的萝卜刀基本上都是塑料材质，而PEI想必较为陌生，在这里给科普下。PEI，中文全名叫聚醚酰亚胺，它是无定形聚醚酰亚胺所制造的超级工程塑料。看到这里你不禁会想，这不还是塑料嘛，为啥定价如此高。先别急，咱接着说，首先，它具有极佳的耐高温及尺寸稳定性，此外，它还有着抗化学性、阻燃、电气性、高强度、高刚性等优点。也因此PEI树脂常被应用到耐高温端子、IC底座、照明设备、FPCB（软性线路板）、液体输送设备、飞机内部零件、医疗设备和家用电器等各个领域。归纳总结一句话：它的各种特性远胜于普通塑料，同时又具有重量轻等优点。

  

![[Read It Later/attachments/04ba09744b9424ed4a24522470d071b5_MD5.jpg]]

  

作为非结晶性塑料，PEI的颜色为琥珀色，即透明深黄色。我个人还是很喜欢这种颜色的，有种80年代的复古感。而且它是半透的，可以透过器身看到书本上的文字。阳光洒下，半透的机身更具魅力。

  

![[Read It Later/attachments/b13ad1fb8111a09c5835e5d437747bdb_MD5.jpg]]

  

  

![[Read It Later/attachments/ab89726291b5f0a93b98a8b13a06b063_MD5.jpg]]

  

萝卜刀的侧面与之前体验过的版本一样，均预留有可装配螺丝批头的凹槽，可供拧旋拧螺丝使用（就连同侧的锁止按键都是相同设计）。不过虽然强度足够，但如此精致的玩具，你舍得用它来拧螺丝嘛。

  

![[Read It Later/attachments/b987a5b28eef00ddf104ff92f8af226c_MD5.jpg]]

  

固定结构用的大小圆栓为亮银色的金属材质，也为橙黄机身增添了些不一样的风采。萝卜刀把时流畅，开合丝滑。闲暇时拿在手中盘玩、戏耍还是蛮解压的。

  

![[Read It Later/attachments/31009fb6532e2c88d423c7f338df0d41_MD5.jpg]]

  

翻出头部，不再是刀式外观，而是集成了撬棍和开瓶器。状若琥珀，阳光直射下更觉迷人。如此精致的EDC玩具。我自是爱不释手。

  

![[Read It Later/attachments/9d422fa93789f4d3352d2662840c169d_MD5.jpg]]

  

FEGVE所推出的这三款萝卜刀虽材质各异，但结构相同。特色上算是各有千秋吧。在推荐层面，如果你是拿来纯把玩，我个人建议是PEI版，它的手感是极好的。而从实用性和性价比上来说，铝合金版自然胜出。颜值的话，钛彩版更为亮眼。当然，不差钱的朋友可以全部拿下。目前我说的这几个版本（包括限量），都还有货。

  

![[Read It Later/attachments/51a437bd6616e63673990002a712bc29_MD5.jpg]]

  

接着再来看下钛尺。众所周知，尺子，在日常生活很常见，特别是对于学生群体来说，使用更是频繁。我们用它来测量物体长度和距离，画直线及各种图形。FEGVE也于今年推出了升级版的二代钛尺。作为文具必备，值得为正上小学的孩子入一把。新版钛尺有原色白及黑色两款，我入手的是后者。费戈给它起了个好听的名字：“钛空尺”。

  

![[Read It Later/attachments/16f73ca22b8353a4113f8e3b6cbc0ba9_MD5.jpg]]

  

印象中费戈之前是出过钛尺的，不过那时它的样式与普通好似并无两样。不过这把钛空尺就不太一样了。它的颜值还是很高的。尺子并不算特别长，仅比正服役的大屏手机略长些。可以做到随身携带，可从容将进笔袋内。

  

![[Read It Later/attachments/add2578df340559973f65cb5ba58510e_MD5.jpg]]

  

尺子顶端带有LOGO的微斜歪把让我联想到了秦陵部分兵马俑头上的歪髻。扁圆的粗大孔洞足可穿插漂亮的各色伞绳。而铭牌两端的凸突横纹隔断也让这把尺子显得不再那么平面化。这个“歪头杀”的设计在危急时还能做为防身利器，以钛合金的硬度，击窗碎石不成问题。

  

![[Read It Later/attachments/13ec746b72e1b9c61740e71c76f83e58_MD5.jpg]]

  

尺子不仅是测量用具，还有着象征事业“步步高升”的美好寓意，拿来送人也是不错的。FEGVE的这把钛尺背面还支持刻字服务，我们可以将持尺人的名字、座右铭，乃至喜爱的诗句、图案激光雕刻在上面。与普通塑质、铁尺不同，一把精美的钛尺可以常久使用，耐用性强，不会老化、生锈。

  

![[Read It Later/attachments/88adc82e07bf369c78db5b058001a04f_MD5.jpg]]

  

整把钛尺的长度为190mm，宽20mm，厚约2mm（仅尺头凸起处为4mm），因为足够薄，所以还可以拿来做阅读书籍时的应急书签来使用。它的重量也只有37克，放在笔袋里并不会增加多少份量。钛空尺为全钛打造而成，表面经[PVD真空镀黑磨砂处理](https://zhida.zhihu.com/search?content_id=654795711&content_type=Answer&match_order=1&q=PVD%E7%9C%9F%E7%A9%BA%E9%95%80%E9%BB%91%E7%A3%A8%E7%A0%82%E5%A4%84%E7%90%86&zhida_source=entity)，手触之细腻舒适。边角处均经过了倒角工艺，并不会出现因为太过分明的棱角而刮硌到手的情况。

  

![[Read It Later/attachments/f9cb384d77d5749979675e5b9dfe436d_MD5.jpg]]

  

尺身上的刻度也是经CNC深雕而成，摸上去能明显感知到凹凸感，清晰且耐磨。而刻度上的最大长度为13厘米和5英寸。对的，它是带有厘米和英寸两种单位的。方便测量不同物体。

  

![[Read It Later/attachments/edbe6c12136c2b54232807c773ee2166_MD5.jpg]]

  

学生常用的塑料尺很容易被刮花，特别是尺子上的刻值会因用的久了而逐渐变得模糊，所以在文具中是最需小心呵护的。但FEGVE的这把钛尺就不一样了，钛制的它可以随意粗用，完全不用烦恼因与其它金属文具混放在一起而被刮花，也不必担心长时间日照暴晒而老化。尺身被刮出痕迹了也没关系，手指轻轻一擦就又恢复如初了。

  

![[Read It Later/attachments/c4b7bf4138a0ea1ad135f5bfc23899aa_MD5.jpg]]

  

日常使用展示，我常把它兼作书签使。儿子写作业、画画时也常拿来用。这把钛尺既不像之前塑料尺般脆弱易损；也不会如钢尺般棱角锐利。使用起来很趁手，也蛮方便。而且日常中真遇到什么危险，还真的能用它来敲击，我试了下，还是挺疼的。另外，所谓好马配好鞍。FEGVE还给随尺送了个毡毛收纳套，很好用。

  

![[Read It Later/attachments/038b33466bd7f4a0ee304e60b0f05aaa_MD5.jpg]]

  

今天给大家分享的这两款，一个是极耐把玩的解压玩具，另个是实用性强，生活、学习中常用到的工具。虽属性各异，但都是不可多得的EDC好物。我都很推荐。这两款，你更心动哪款呢？欢迎评论区回复哟！

[章节] 引言

今天我们来开箱苹果最贵的键盘之一，1,399块，名字也很长，官方全名是，配备触控ID和数字小键盘的妙控键盘，这个价格，1毫米的键程薄膜，那为什么我要买这块键盘呢，这块键盘好用吗，那让我们开箱吧。

[章节] 开箱

包装背面右上角有指纹识别的图标，通过这一点就不容易买错，将纸质挂钩向外拉，内核就可以整个抽出了，阻尼感是有设计过的，随包装附赠了原厂 USB - C，黑色编织线，这个黑色线外面是没有卖的哦，所以还蛮稀有的，苹果的键盘10年间基本没变过造型。

[章节] 外观

只是 R 角大一些些，黑色键盘搭配银色铝金属本体，黑白对比呈现一种冷峻的高级感，和 Studio Display 相衬的银配黑色，与 Mac Pro 相得益彰，虽然大家说这比白色贵 150 块是“黑色税”，但黑色看起来确实更 Pro 一点，买之前特意问了一下，为什么一样的东西黑色会贵150块，店员回答是材质不一样，实际体验的话，黑色好处在于不反光吧。

[章节] 手感

更好看只不过用久了也更容易打油，背面的开关很眼熟，像是从 iPod Shuffle 上拔下来的一样，这也算是苹果的设计延续吧，按键采用改良的剪刀脚结构，提供更稳定的按压与回馈感，就算没按到键帽的中央，也不会导致按键歪斜一边，用过苹果键盘很容易被它的 Q 弹回馈力道吸引。

[章节] 快捷键

连上Mac，按住 option 键，可以查看蓝牙版本，大概是从蓝牙 3.0 升级到蓝牙 5.2 的关系，输入延迟更低，唤醒电脑的速度也非常快，感觉 24 款的续航比 21 款好得多，充一次电可以用一个月，通常不需要特意关闭，妙控系列配件是有线和无线双模的，除了鼠标，这种插上就可以自动配对的体验很方便，有别于旧款，单按 F5 是听写，按住 F5 和 Siri 说话，不过做不到像 Apple TV 7 的遥控器那样，因为现在 Mac 台式机都还没有内置麦克风，接下来介绍几个妙控键盘才有的键吧，锁定键，中途离开按一下就可以了，安心，地球键不只是用来切换输入法，而是在 Command Option，Control 之外的一个修饰键，globe + E 选 emoji，globe + F 全屏，globe + N 打开通知中心，是副厂键盘的 fn 键做不到的，macOS Sequoia 后引入了不少 Windows 元素，globe + control + 方向键分屏，想起 Aero Snap 了，甚至 PC 上的菜单键也来到 Mac，短键盘可以用 control + return 代替，等了整整 30 年，这样在 iPad 上方便多了，不用抬手点屏幕，当然这么多快捷键，人脑记不住，command + shift + /，想不起来的功能直接搜，系统还会用个小箭头告诉你，这个功能藏在哪个菜单里，说到这里，可能有些人会问，1399块。

[章节] 安全性（Touch ID）

为什么不买手感更好的机械键盘呢，其实这么多年从 iPhone 5S 用到现在，早就习惯 Touch ID 了，解锁 Mac 切换，用户，使用密码管理器填充密码，从 APP store 下载或者订阅付费，乃至终端的权限，相比通过 Apple Watch 解锁，锁妙控键盘的优势在于，双手不用离开主键区，将唤醒 → 验证 → 进入这三步，压缩成一个近乎无感的瞬间，哦对，外接键盘上的 Touch ID 依赖于 Apple 芯片的安全隔区，所以我这台 19 款 Mac Pro 是不支持 Touch ID 的噢，当然 PC 自然也不支持，连接是能连接上的，也可以用来打游戏，但是顶部的那一排按钮就没有用了，那 iPad 呢，也不行，Touch ID 理论上完全可以做到，在 iPad 上，应该就是懒得做吧。

[章节] 选购建议（长款还是短款）

如果你要我推荐买长的还是短的好，如果你桌面够大，长期与文字打交道，每天要用 Excel，或有剪辑的需求，可以选全尺寸的，方向键更舒服，又有独立的翻页键，盲操提供更高的容错率，而且就差 200 块，如果你桌面比较局促，或者喜欢和妙控板一起使用，短款更合适，可以塞进显示器增高架下面，配合 Vision Pro 打字的话，可以放腿上，不需要正襟危坐，亦可作为 Apple TV 的键盘在客厅使用，最后，这把键盘并不完美。

# EDC文化到底是什么？男生出门装备清单详解

[![[Read It Later/attachments/218ecdd79ee4ce4981e9e40cf262e4d3_MD5.jpg]]](https://www.zhihu.com/people/xi-men-chui-hui-70)

男生出门包里放什么这个问题，如果你只是想满足功能上的需求，其实是一个再简单不过的问题。因为他是一个生活甚至是生存技能，无须多言。

但如果你是希望你想把自己的糙汉直男生活带出点色彩的话。

那还真的是有的聊聊，因为他涉及到一种潮流文化，叫翻包文化，简称[EDC](https://zhida.zhihu.com/search?content_id=121682855&content_type=Article&match_order=1&q=EDC&zhida_source=entity),everyday carry。

意为为了生活，工作等需求，每天携带的必备物件。这个概念最早源于上世纪六十年代的冷战时期，处于核威胁的美国佬认为世界大战就要爆发，人类将要灭亡，他们就开始为这个事情做准备，希望到时候完全依赖自己可以在战时求生，这群人被称为[survivalist](https://zhida.zhihu.com/search?content_id=121682855&content_type=Article&match_order=1&q=survivalist&zhida_source=entity)。而EDC就是他们的生存装备。

![[Read It Later/attachments/25dfae251e07ffe81046242940be7d7b_MD5.jpg]]

  

以前，有EDC习惯的人基本有2种。一种是实战人士，另一种是喜好野外生存人士。但进入到和平年代后，EDC从生存狂热人士解脱出来后，渐渐的演变成了一种文化艺术，一种让人尽情把玩和喜爱的东西。它同样是一种爱好，也是一种品味，也是一种彰显个性的产物。

它绝对是每一位高品质男性表达自己生活态度，个人性格的完美载体。你每日携带和使用的东西也反应了很多关于你的生活，你的经历，你的态度，承载了太多关于你的记忆。同时，优化你的EDC装备也是你对生活经历的记录，以及人生成长的印记。

![[Read It Later/attachments/ccaaa794b3d23ef03a55cdefd6d3e495_MD5.jpg]]

时至今日，EDC已经是世界上一种表达生活的潮流方式。无数爱好者将自己身上所携带的物品摆放整齐，用照片记录后在放上社交媒体。它不单单是平时随身的物件，这里面还包含了主人们的习惯，喜好以及个性释放，自我表达的态度。

![[Read It Later/attachments/e459376a2ff10369a0c4efe01273882d_MD5.jpg]]

  

虽然对于任意一个EDC爱好者都并不存在一个标准答案，因为每个edc都应该是为自己而定制的。但仍然有一些品类清单是大部分edc玩家所追捧的，这些品类选择的原则仍然是edc最初的概念——为生活，工作的必需品。下面我列举我的edc清单：

1.钱包。虽然现在支付已经可以完全依赖于手机，但钱包依然可以存放我们的一些卡片，如信用卡，身份证，工作证，部分现金等；

![[Read It Later/attachments/7cd5ebf89e79fadef0d53de43d9fdd35_MD5.jpg]]

钱包的品牌种类有很多，款式的差异也比较大，可以说不同的场合都会有不同的样式，表现出不同的态度。推荐几个我个人比较喜欢的钱包。除了奢侈品那几个以为，推荐一些亲民但很有格调的牌子

1.[BRAUN BUFFEL](https://zhida.zhihu.com/search?content_id=121682855&content_type=Article&match_order=1&q=BRAUN+BUFFEL&zhida_source=entity)

德国的一个小众品牌，但已经有百年历史了。品牌呈现给人们的是一个典雅的世界。在温柔的灯光下，通透的玻璃窗折射出一道道美丽的光线，照在各式各样的皮具上，显得光滑而又充满质感。金色的牛形标志贴在磨砂玻璃上，格外引人注目。我一般正式工作日都会选择用它。

2.[babama](https://zhida.zhihu.com/search?content_id=121682855&content_type=Article&match_order=1&q=babama&zhida_source=entity)

本土原创的潮流品牌，日常穿搭配饰也不会觉得很抢眼，同时也具有时尚感，另外价格也不是太贵。品牌和老夫子，守护荒野，石黑亚矢子等都有联名款，表达了现代年轻人的时尚主张。关键是价格也十分亲民。

2.钥匙扣。钥匙对我们生活来说还是非常重要的物品，对大部分人来说，基本是必不可少的物件，所以一款精致的钥匙扣是彰显你生活态度的必备之物；

![[Read It Later/attachments/fe6df27534a21f4366771e514b244607_MD5.jpg]]

这是edc用品的一个重要分支，现在很多作品可能在你看到这个文章的时候已经买不到了，推荐一些还不错的常规款，有品位的同事也易于选择。

1.[versace美杜莎](https://zhida.zhihu.com/search?content_id=121682855&content_type=Article&match_order=1&q=versace%E7%BE%8E%E6%9D%9C%E8%8E%8E&zhida_source=entity)

品牌不用介绍了，是一个奢侈品牌。关键是这款美杜莎钥匙扣作为20年的新款，真的是很漂亮，男女都适用，多色可选。

2.万宝龙大班狼图腾

品牌也不用多介绍了。大班系列这款狼图腾钥匙扣采用了软皮粒纹，整体做工非常好，值得入手。

3.[星球熊马卡龙](https://zhida.zhihu.com/search?content_id=121682855&content_type=Article&match_order=1&q=%E6%98%9F%E7%90%83%E7%86%8A%E9%A9%AC%E5%8D%A1%E9%BE%99&zhida_source=entity)

马卡龙配色的星球熊钥匙扣金属感十足的同时也有一丝俏皮气息，如果你年纪不是很大，可以买一个，整体金属电镀的同时嵌入施华洛世奇水晶，也很有品味。

3.钢笔。钢笔无疑是男士日常生活中最具文艺气质的物品。而做工和理念极致优良的战术笔绝对是展现品味的最佳事物；（可以参考中山英俊的作品）

![[Read It Later/attachments/b0e86a05f2f077d885fd719f7d93dd51_MD5.jpg]]

战术笔是的选择有很多，并不是贵的就一定好，中山英俊的作品大家都想要，但能买到的却不多。同样，推荐几个可以购买且颜值，功能都在线的单品。

1.[京造战术笔](https://zhida.zhihu.com/search?content_id=121682855&content_type=Article&match_order=1&q=%E4%BA%AC%E9%80%A0%E6%88%98%E6%9C%AF%E7%AC%94&zhida_source=entity)

价格很亲民，且颜值相当在线，采用龙骨镂空设计，钨钢打击头，进口笔芯，书写和战术用途都不错。官方也对这款战术笔打出了“文武双全”的口号。

2.[cooyoo陀螺枪](https://zhida.zhihu.com/search?content_id=121682855&content_type=Article&match_order=1&q=cooyoo%E9%99%80%E8%9E%BA%E6%9E%AA&zhida_source=entity)

cooyoo的陀螺枪一共有三种材质可以选择，分别是钛合金，锆合金，钛马。产品经过了反复打磨，外观和握感非常舒适。

3.[gerber多功能战术笔](https://zhida.zhihu.com/search?content_id=121682855&content_type=Article&match_order=1&q=gerber%E5%A4%9A%E5%8A%9F%E8%83%BD%E6%88%98%E6%9C%AF%E7%AC%94&zhida_source=entity)

这款来头不小，户外大神贝爷亲情代言的一款战术笔，笔身采用钢+蜡酸盐涂层非常耐用，颜值当当响。

4.手电筒。当有50%机率下雨的时候，大部分都会带雨伞，那每天都有100%机率黑暗，为什么不放一个手电筒在包里呢？

![[Read It Later/attachments/fc318d05a98957f888cacd011784fd51_MD5.jpg]]

![[Read It Later/attachments/c40bfeb15d7f573dc06a289241c41dac_MD5.jpg]]

这个领域我涉猎不多，特地问了大神小白入门可选的几个，推荐务本这个品牌功能性和颜值都不错。

  

5.多功能工具。这些看起来简单的小东西，为生活起了很多便利。比如工具刀，开瓶器，虎指之类的。这些物件如果呢把它当成edc来看，就不仅仅是它的功能性价值了，更像是一种奢侈品，但与奢侈品不同的是，在你遇到突发状况时候，可真的是有实用价值的。

![[Read It Later/attachments/0cc48acdcc6d807637781a966c544d99_MD5.jpg]]

![[Read It Later/attachments/9ab53a79a4a2764ac49e1d575ccd126f_MD5.jpg]]

![[Read It Later/attachments/90e6cb8cfee5ea24d2a51d8a86637e4d_MD5.jpg]]

  

6.减压玩具。我首推指尖陀螺，在所有edc清单中我特别喜欢陀螺，陀螺与指尖的反馈以及发出的声响给我在无聊时候一种非常放松的感觉。

![[Read It Later/attachments/b181655fce02f8aefcb740d2182c58fc_MD5.jpg]]

明代张岱的《陶庵梦忆》中的《祁止祥癖》中说过：“人无癖不可与交，以其无深情也；人无痴不可与交，以其无真气也”。这句话我特别喜欢，生活是美好还是残酷，完全取决于你对生活的态度，什么样的东西能取悦你，你就会是别人眼中那样的人。为什么不热爱你的生活，适度的癖好绝对会起到积极的作用。

车钥匙是别在挂包上，但到家或单位这两样都放下。

  

以下是我有收藏但基本没带在身上的

  

文章中的手电类我也有收藏，不过偏实用为主。个人认为目前EDC手电类比较实用的应该是这样规格：

使用电池：锂电18500，这种电池比18650短，但比18350和16340长，续航能力中等，在续航能力与体积比方面达到一个较好的平衡。18350的18650的次之。16340的基本完全不考虑。

分档：磁控无级亮度是最好的配置，虽然这种控制芯片决定电流（亮度）不能太大，但考虑到LED手电的高亮热力真的夸张，没这种配置的真的不好用

亮度：最高500~1000lm都可以，实际上很多手电的高亮最多就只能尺寸2~3分钟，否则就烫手到想扔掉。一般300~500lm的亮度再结合上面的磁控已经很实用。

材质：从收藏角度讲，最好的是紫铜，其次是磷铜（青铜），两种铜都是约玩越漂亮，钛合金也不错。不锈钢颜值不错，跟钛都可以作色。但不锈钢重且导热迅速反而不好把握。铝合金是大路货， 不过我收到的很多就是铝合金，无他，主要考虑作为消耗品，用烂了就买。

  

文章照片中还有指虎类，这是一类比较“斯文”的武器，相对于刀类，还是比较克制和友好。个人也有收藏，但基本不带上街：因为我收藏的很多指虎价值都不便宜（文章照片中如果是外国原版的估计也要1~2K起），很多还是绝版，如果因为某个安检被收缴就真的欲哭无泪了。其实要发挥指虎的功能，可以选工程树脂材料的或G10的，量大又便宜，虽然强度不如金属的，但使用起来不心痛。

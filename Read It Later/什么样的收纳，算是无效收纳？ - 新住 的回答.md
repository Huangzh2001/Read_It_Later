​这几天家里好几个人感冒，买的感冒药稍微多了点。

然后老妈就自告奋勇搞收纳，完了还给我嘚瑟，让我看她收纳的咋样，追不追得上我这家居博主的水平。

  

![[Read It Later/attachments/fda615f0cfa7cb5bbeb1b620b31dddc8_MD5.jpg]]

  

我一看，把我给整笑了。

老妈可仔细地把药超出的边缘剪掉了，然后整整齐齐地把药让进了一个闲置的纸巾盒里，这份为了收纳的努力，我是服气的。

  

![[Read It Later/attachments/448571343548e720dbc69f76c3ad3fa4_MD5.jpg]]

  

但收纳效果吗？

这简直就是典型的无效收纳……

只把东西塞进去，或者放整齐了，但却没考虑东西拿取方不方便。

这个药往这盒子里一装，外面的包装也没有了，日期、药品名全都没有了，大概率是会放一阵之后，突然有一天发现这还有一盒药，然后因为不知道是什么药，或者有没有过期，而丢掉。

  

![[Read It Later/attachments/e3a9c81ad99725c7eb21a7052f909701_MD5.jpg]]

  

正确药品应该是如图，不仅能把药品集中地藏进柜子里，在需要用的时候，找起来也更方便，也有足够的信息确保我不吃错药。

其实搞出来类似的无效收纳，可不止我妈一个，也不仅限于药品收纳这一件事，在我们的日常生活中无效收纳非常常见，甚至习以为常成为我们习惯。

本期我们就来聊一些典型的无效收纳，看看你家有没有？

## 玩具收纳

玩具多且形状不一，又占地方，其收纳是很多家庭的痛点。

  

![[Read It Later/attachments/a4730a3c8363009a873a1acc0832cd66_MD5.jpg]]

  

  

甚至都有一种言论：有娃之后，家里根本就不可能整洁。

我不赞成，但我理解大家对于收纳玩具屡遭挫折的心，因为我家有两个小子，的确不易。

  

![[Read It Later/attachments/7ead27c87dc48e33825ab6e8a5331dca_MD5.jpg]]

  

关于玩具收纳，大部分家庭的路数，跟我家最开始的时候一样，找几个大箱子，然后一股脑的把玩具收进去。

虽然这样收的时候效率很高，但小孩玩的时候，也确实不好找想要的那一个或者那一类，导致前面看到的，一股脑全倒出来，每天都是要收一大堆。

这样的收纳，算是典型的无效玩具收纳，孩子难找，大人费劲，家里乱。

玩具收纳正解：

经过了我对两个孩子的摸索，我家目前已经算是有明确的方案了，大致分两步走：

**①丢一部分玩具**

小孩的玩具体量太大了，不丢根本就不成，而且她也在长大，很多玩具确实也不玩了。

让他抉择丢哪些显然不太可能，因为我试过，俩娃一样样的，一个都舍不得丢，即使是已经断胳膊断腿、少轮子没翅膀的，它也不愿意丢，人可能天生就有损失厌恶吧。

那这时候，你可以帮他抉择，可以弄一个大箱子，把你认为他可能并不需要的玩具全部收集起来，放在家里的储物间或者角落里。

他想起来了，到处找的玩具，你就告诉他让他在大箱子里找，找到然后放到长玩的玩具收纳区。

过了好几个月，它都没有带走的玩具，你就可以悄悄丢掉了，然后再收拾新的玩具，让他自己再慢慢去挑，如此往复即可。

**②分类置物货架收纳**

  

![[Read It Later/attachments/4080dd76b65989c6ebd7439a732ef05c_MD5.jpg]]

  

在大箱子准备丢的玩具之外，当然得有个畅玩玩具收纳区了，

核心是分类，确保它要玩的一类玩具，在一起，如此，他便不再是一次倒出来所有玩具了。

  

![[Read It Later/attachments/543ed1558c7e593185a9031f4ce40084_MD5.jpg]]

  

为了节省空间，不显乱，可以弄一个架子，用门帘遮起来。

类似的，也可以塞进客厅的柜子里、电视柜的抽屉里、甚至是买的那种儿童玩具收纳架里。

## 衣柜收纳

这应该是许多家庭衣柜的现状，一个挂衣格，然后多个小格子，衣物收纳主要靠叠衣。

  

![[Read It Later/attachments/256ee23435f5779b9d5aa6ba86a26120_MD5.jpg]]

  

发展到后期，衣服实在多的没办法放，甚至连挂衣区，也干脆全部用作叠衣区。

其实在叠好的时候，还是挺佩服自己的，而且觉得这样收纳，也没有什么大问题。

  

![[Read It Later/attachments/b2e4cb02bc2c3fe18b579810c60d192b_MD5.jpg]]

  

可一旦用起来，找某件衣服那简直就是在衣服堆里“刨”衣服，非常不方便是其一。

其二还会因为要拿取一件衣服而把整个一大格子的衣服全部弄乱，导致日常衣柜里的状态不仅是乱的，还摇摇欲坠，有时候一开门都会掉衣服下来。

显然这个广泛流行的衣柜叠衣大法，并不好用，是典型的无效收纳！

许多家庭发现问题于是着手解决，但可惜还是踩坑了，下面讲的这些大家避坑：

**①利用叠衣板**

  

![[Read It Later/attachments/4ba0d6f515a58e5247522ec8f564749f_MD5.jpg]]

  

其实本质上还是跟叠衣一样，甚至比叠衣还要费的功夫大一点，不过是看起来整洁了一点，好似拿取也方便了一点，实则还是不能一眼辨认要取的衣服，得一个一个翻。

还更占空间，本来不大的衣柜，这么一搞空间更紧张了。

**②利用绑带**  

  

![[Read It Later/attachments/e6125f0fdb62e8daf85436bb0b3d4125_MD5.jpg]]

  

有卷成大春卷，绑起来，堆进衣柜的，拿取还是得靠刨。

  

![[Read It Later/attachments/5a548a2cf09daca445f1b40af30744a2_MD5.jpg]]

  

还有精致一点的，给衣服内衬一个叠衣板，然后外面留出来一个绑带一绑。

  

![[Read It Later/attachments/99b76dc1804515a932f66946db49a533_MD5.jpg]]

  

讲真，如果真的能每天、每时每刻能坚持这么干，那衣柜里确实够整洁，也基本上能拿取方便。

可问题就在于我们是生活，不是衣服店里专门搞陈列的上货员，根本无法坚持这么干，而且也没有那么统一的衣服。

**③利用叠放收纳篮**

如果这个篮子，真的可以像图中这样，可以自由抽取衣物，那这个篮子绝对算是衣柜收纳神器。

  

![[Read It Later/attachments/381928d60ad254fcdea194eaf04c0d9c_MD5.jpg]]

  

但可惜，它基本抽拉不动，想要取出下面的衣物，还得把上面的所有篮子都搬开才能实现。

**④搞一些怪异的创新**

除了要避坑“鸡肋”的收纳物件之外，还需避坑一些并不靠谱的怪异DIY灵感。

比如这个案例中，给柜子上贴了一个隔板，然后利用鹅型裤架去收纳裤子。

  

![[Read It Later/attachments/16f616b20fd85ab3b4755522254fee6a_MD5.jpg]]

  

  

那么问题来了，左侧空的地方，到底要不要利用，要利用，注定靠内的裤子拿不出来，不利用，难道空这么大的空间就为收纳这一排裤子。

**衣柜收纳正解：**

别去整那些没用的，目前最好用的衣柜布局便是：黄金区不留柜格，然后用挂衣杆+抽屉式收纳箱去布局。

上下非黄金收纳区，可以放一些不常用的物品，中间得留一个大的挂衣区。

  

![[Read It Later/attachments/1e121666dc3de71e1af7a5ce67a4b4af_MD5.jpg]]

  

然后这个大的挂衣区，就靠抽屉式收纳箱来灵活布局，没长衣的情况下，直接如上图布局，上面短衣，下面衣物分类收纳。

  

![[Read It Later/attachments/52cda27032730ef20ad99f5286fc9b25_MD5.jpg]]

  

衣服好找，且拿取方便，无论是挂衣还是抽屉内放衣服，都比叠衣要更好找，还不容易乱。。

收进去的时候，也不麻烦，直接叠一摞，竖着放进抽屉即可，由于抽屉的存在，这么放是要比叠衣能塞得更多。

  

![[Read It Later/attachments/e679a335108e99b82e5b39041352a72b_MD5.jpg]]

  

有长衣了，则挪动抽屉式收纳箱，让长衣可以垂下来布局上也更灵活。

如果家里衣柜不够大了，还可以选个白色的收纳盒，颜值更高。

  

![[Read It Later/attachments/b6cd6a640a4527981e5bed9430e86b7a_MD5.jpg]]

  

在必要的时候，还可以拿出衣柜找一个角落放着，也不会显得家里乱。

如果家里衣柜足够大，能腾出来挂裤子的地方，那更好。

  

![[Read It Later/attachments/c400bd187f70e8f99abb134ab9c31fdc_MD5.jpg]]

  

可以借助滑轨裤架+鹅形裤架去收纳裤子，收纳得够多，查找、拿取也更方便。

## 杂物收纳

对于杂物收纳，我们经常只能做到把物品塞进柜子里，摆放整齐，而忽略拿取问题，比如：

**①橱柜地柜里的杂物**

  

![[Read It Later/attachments/c41f2ea63237c565be5a55dda839eb6e_MD5.jpg]]

  

橱柜里，我们把物品全部放进去，但当要用到深处那个东西时，就需要把所有东西都拿出来。

  

![[Read It Later/attachments/6af76b0beab39d078efdb91328b3b50b_MD5.jpg]]

  

**地柜杂物收纳正解：**

可其实，如果要确保物品好拿，我们是需要抽屉或者抽拉装置的。

  

![[Read It Later/attachments/1efbbaabe091e5e6b69455a8a23a17be_MD5.jpg]]

  

这也是为何这种抽拉装置改造地柜，之所以大受欢迎的原因，我们完全可以效仿。

**②调味品收纳**

很多人理解的调味品的收纳，就是整整齐齐把调味品放进柜子里。

  

![[Read It Later/attachments/d4a872fa49cc9a583f89a362642906de_MD5.jpg]]

  

导致每做一顿饭，就得去整理一次柜子的调味品，麻烦

**调味品收纳正解：**

  

![[Read It Later/attachments/09ed2a9f32d60b95c30aec1bb10c43a6_MD5.jpg]]

  

可其实，有现成的[旋转收纳盘](https://zhida.zhihu.com/search?content_id=593025797&content_type=Answer&match_order=1&q=%E6%97%8B%E8%BD%AC%E6%94%B6%E7%BA%B3%E7%9B%98&zhida_source=entity)，可以作为调味品收纳的辅助工具，深处旋转一下即可到跟前，非常方便。

浅口更适合瓶装和常用品；

深口则更适合袋装品，放东西更稳固。

**③鞋子收纳**

前一段时间流行的这种鞋子收纳架，也是如此倒是能把鞋子摆放整齐，而且也有一定的扩容作用。

  

![[Read It Later/attachments/b930b2a434034905c7a17e117de294f8_MD5.jpg]]

  

可拿的时候，不方便，放的时候也不方便。

  

![[Read It Later/attachments/ce8ea425451a3c729df7e76007e78a51_MD5.jpg]]

  

**鞋子收纳正解：**

  

![[Read It Later/attachments/5bce82ff89285e2fe1f8c97afa17ba99_MD5.jpg]]

  

  

真的不如利用[伸缩层板](https://zhida.zhihu.com/search?content_id=593025797&content_type=Answer&match_order=1&q=%E4%BC%B8%E7%BC%A9%E5%B1%82%E6%9D%BF&zhida_source=entity)，去给鞋柜扩容，就跟普通的层板拿取方便程度类似，只不过是把垂直的空间利用得更到位了。

**④囤货柜、零食柜收纳**

零食囤货柜收纳，也有类似的问题。

  

![[Read It Later/attachments/59117db1d8a2fd568b853aafdcdad61f_MD5.jpg]]

  

  

我们往往只知用收纳盒，但不知道用收纳盒的意义，所以乱七八糟弄了一堆有用没用的收纳盒。

**杂物收纳正解：**

可实际上柜内的收纳盒，应该承担三个作用：

其一，让柜内更整洁；

其二，让物品可以通过收纳盒分类，从而能快速找到想要的物品；

其三，盒子最好是能让物品竖起来，让人拿取更方便。

这其实也是我做收纳的所有追求，大家不妨看下自家的收纳，有没有违背这些追求，如果有，那妥妥就是无效收纳，需要改进了。

**NO.1 统一收纳**

[统一收纳法](https://zhida.zhihu.com/search?content_id=700135403&content_type=Answer&match_order=1&q=%E7%BB%9F%E4%B8%80%E6%94%B6%E7%BA%B3%E6%B3%95&zhida_source=entity)就是拆掉物品的原包装，全部装到外观、尺寸一样的收纳盒里。

它在我这儿还有个名字——**过度收纳。**它不是为了把东西变得整齐好拿，**它就是为了收纳而收纳。**

![[Read It Later/attachments/4fcd15756d1ee88e97f2bbff783e4974_MD5.jpg]]

但是，居然有网红博主对厨房调味料下手……

调料不多的话可以理解，毕竟整整齐齐摆一起好看；但是调料多的话，一个一个拆开分装是在干嘛？我真的满脑子问号。

![[Read It Later/attachments/38444397df6e046bdfe91be9f45276a4_MD5.jpg]]

有的调料肉眼看上去区别不大，比如盐和糖，还要注意把标签那一面朝外放。

![[Read It Later/attachments/cd9d410a656683551db2d62e2428a0dc_MD5.jpg]]

可能有人要说了，真空收纳袋放衣服不行，那放被子总可以了吧？

也不见得，**羊毛被和化纤被可以，但是羽绒被和蚕丝被不行**。

羽绒被保暖的关键就在于绒朵的高度蓬松，压缩会破坏绒朵的结构，也就是蓬松度会变差；至于蚕丝被的话，蚕丝含有丝胶，长时间压缩会黏在一起，而且纤维受损后容易变质。

羽绒被和蚕丝被的收纳可以用**宜家思库布**，四面都有挡板yyds；**霜山最大号的收纳袋**也行，亚麻材质和防水内衬都很厚实。

其实也很简单，那就是常用的一定要漏出来，可以使用透明的盒子，一眼看到需要的物而且要放在好拿取的地方。

意思就是衣柜上面放轻的，重的都放在下面；中间是整个衣柜最好的位置，容易拿取，所以常用的要放在中间；左右两边放东西时可以考虑玄关、屋门、地垫等物品，综合来看收纳效果更好。

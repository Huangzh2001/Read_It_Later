吃藻躺平。

![[Read It Later/attachments/c3c9fcc90e73b1abad41334756c69cec_MD5.jpg]]

两年前我是躺平吧小吧主，大吧主平时吃油炸蟑螂补充营养，另一个小吧主就是躺平主义创始人骆华忠，我养藻补充营养，我们三个当时在吧里宣传躺平理念，一个星期不到，聚了30万人，热度排名每天都是贴吧第一。

大吧主吃蟑螂补充蛋白质把很多吧友劝退了，所以吧友都支持我的吃藻躺平方案，因为藻类蛋白质高达50％以上，没那么难吃。

![[Read It Later/attachments/8eb5150af5c60dd3a06a9fc2d805c42c_MD5.jpg]]

可问题来了，藻类虽然增殖速度快，但是也赶不上人的消耗速度，所以我开始研究如何让藻类繁殖更快。

![[Read It Later/attachments/df2f4053a63d689ca7ae3fa60f43dfd9_MD5.jpg]]

事实证明4大桶[小球藻](https://zhida.zhihu.com/search?content_id=592328746&content_type=Answer&match_order=1&q=%E5%B0%8F%E7%90%83%E8%97%BB&zhida_source=entity)还不足以让人躺平，但当时主要是想让藻类分裂速度加快，摸着石头过河。

![[Read It Later/attachments/46adc1615ca7d51a0abc573c9d226537_MD5.jpg]]

  

![[Read It Later/attachments/68a7a9fabc8c203aa7d2aae6b9a3304a_MD5.jpg]]

藻类普遍对[红光利用率](https://zhida.zhihu.com/search?content_id=592328746&content_type=Answer&match_order=1&q=%E7%BA%A2%E5%85%89%E5%88%A9%E7%94%A8%E7%8E%87&zhida_source=entity)较大，因此我为了让藻类一天24小时不停分裂，搭建了一个[扩培室](https://zhida.zhihu.com/search?content_id=592328746&content_type=Answer&match_order=1&q=%E6%89%A9%E5%9F%B9%E5%AE%A4&zhida_source=entity)，提高温度的同时增加了光照效率，过去白天光照10小时，现在一天24小时，效率翻倍。但是经过学习探索，晚上呼吸作用对于藻类也是很重要的，追求极致的繁殖速度会导致藻类品相不佳营养失衡。

但是无论如何，小球藻繁育速度上来了。实验总体上成功了。谁知道就在这个时候，我的小球藻繁育实验引起了官方的注意，甚至有官媒带头炒作，把我跟三年历史时期的事情相联系

![[Read It Later/attachments/fe0ac2c326e8eb75b1d01dafbbcb9b41_MD5.jpg]]

1960年，国家确实发展过小球藻代食品运动，尽管出了很多问题，但是总体上也是有效果的。

紧接着，一些大V开始跟风，想把我养小球藻的事情炒上热搜

![[Read It Later/attachments/9db5c82aea05bd57a5bf096683eca698_MD5.jpg]]

有微博上的人专门来贴吧回复我，我就去贴吧搜了一下小球藻，铺天盖地，全是转发的，据说QQ空间已经传疯了

![[Read It Later/attachments/b30d964db5d06c2b7af6c13796d0ce53_MD5.jpg]]

这还了得，本想偷偷在贴吧跟30万躺平吧吧友实现躺平，日拱一卒实现营养自由，没想到这么快就暴露了。

官方也是一点也不惯着我，稍微闻到了点风吹草动，立马封了我百度账号。

![[Read It Later/attachments/2e577549ebb3aacf316368011440f254_MD5.jpg]]

我只能用小号回吧里解释情况

![[Read It Later/attachments/967ea6b981ee91fa40bd891a2430d377_MD5.jpg]]

活人不能让尿憋死，贴吧容不下我，我又去了Bilibili，发视频吧原贴里的截图总结在一个视频里

![[Read It Later/attachments/70d2fd26144da44904125ef2f86d1f19_MD5.jpg]]

视频刚发出来，吧友们蜂拥而至，一两个小时的功夫，点赞差点破万。

不知道是什么原因，这个视频被判定违规强行下架

我去问客服，客服支支吾吾，不久我的bilibili账号也被彻底强制注销，头像也白了，主页点不进去。

![[Read It Later/attachments/2c37e212c3a04c48bfe86f53183b98d9_MD5.jpg]]

（目前新的b站号和知乎同名）

一时间我手足无措，我不是日本战犯，手上也没有血案，不过是养了点藻，就被全网追着封，简直不把我当人了。

更难以置信的是没过多久，我因为发表不当言论被叫去喝茶了。

喝茶以后刀枪入库马放南山，过了两个月，我又开始转向研究[螺旋藻](https://zhida.zhihu.com/search?content_id=592328746&content_type=Answer&match_order=1&q=%E8%9E%BA%E6%97%8B%E8%97%BB&zhida_source=entity)，没想到这次我又因为植物营养中的化学品被抓了。

养藻，进了2次公安局。

藻类，到底藏了什么秘密？

撬动剥削结构？生产关系洗牌？

我只知道，等我实现了人类营养自由，肯定会得罪无数人，但我一往无前，并且后继有人。

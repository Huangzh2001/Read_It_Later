# 为什么有的人很聪明，可就是一事无成呢？

因为遇到了达·芬奇诅咒。

有一类人他们非常聪明，精神生活无比丰富，特别喜欢学习，有很多爱好，对各种事情都了解，在各个学科都有涉猎。

但是，这些人没有取得什么重大成就。他们年轻的时候充满信心，年龄大了却有一种失落感，觉得浪费了自己的才华。

这些人可能陷入了达·芬奇诅咒。

[《达·芬奇诅咒》](https://zhida.zhihu.com/search?content_id=758543056&content_type=Answer&match_order=1&q=%E3%80%8A%E8%BE%BE%C2%B7%E8%8A%AC%E5%A5%87%E8%AF%85%E5%92%92%E3%80%8B&zhida_source=entity)是几年前出版的一本书，作者叫[莱昂纳多·洛斯彭纳托](https://zhida.zhihu.com/search?content_id=758543056&content_type=Answer&match_order=1&q=%E8%8E%B1%E6%98%82%E7%BA%B3%E5%A4%9A%C2%B7%E6%B4%9B%E6%96%AF%E5%BD%AD%E7%BA%B3%E6%89%98&zhida_source=entity)。

达·芬奇是一位画家，还是一位建筑师，他擅长人体解剖，在科学上也有很多成就，还搞了很多技术上的发明创造。可以说达·芬奇是个全才型的天才。

“达·芬奇诅咒”的意思则是一个人也像达·芬奇一样对什么东西都感兴趣，也是个全才，但结果却没能取得什么成就，一事无成。

现在很多人认为真正的人才应该是“通才”，不仅擅长自己领域的东西，而且涉猎广泛，最好琴棋书画都会，十八般武艺都懂。好像我们每个人都应该学一点人文艺术、历史政治方面的知识，这样才能借鉴各个领域的思想，解决复杂的问题。

但是请注意，了解其他领域，可不是让你平均用力。要知道你不是达·芬奇，现在也不是达·芬奇的时代，如今是一个专才的世界。

达·芬奇是16世纪的人，那时其实没有多少知识。大部分人都是文盲，一个真正的聪明人一两年学完一个学科也是可能的。现在别说一个学科，你想在某个学科的某个细分领域达到专家水平，都需要很多年的训练。

想在现代社会中成为专家，你必须花大量的时间在一个领域进行深入学习。

而具有“[达·芬奇人格](https://zhida.zhihu.com/search?content_id=758543056&content_type=Answer&match_order=1&q=%E8%BE%BE%C2%B7%E8%8A%AC%E5%A5%87%E4%BA%BA%E6%A0%BC&zhida_source=entity)”的人，感兴趣的领域实在太多了。他们看什么都有强烈的好奇心，总会被更新奇的事物所吸引，以至于根本没办法静下心来专注于一个领域。

《达·芬奇诅咒》的洛斯彭纳托给具有“达·芬奇人格”的人提出的建议是，最好寻找一个能综合利用你的各项技能的活动。这个活动一定要复杂，因为聪明人喜欢复杂的东西，也只有复杂的东西才能体现你的能力。

洛斯彭纳托说选择的领域要考虑三个标准：第一，你得确实喜欢这个领域；第二，你得在这个领域中有天赋；第三，这个领域必须能让你挣到钱。

最后洛斯彭纳托还给了两个性格方面的建议，可以说是肺腑之言。一个是聪明人都喜欢拖延，达·芬奇本人就非常爱拖延，而你想做事就得把拖延的毛病给改掉。

另一个是你得克服自恋情绪。很多聪明人都自恋，适度的自恋可以给你自信，但自恋过度，就会在极度的自信和挫败之间摇摆。今天觉得这个事情有意思就特别想干，热情一旦没了就感到无聊乃至郁闷，想做成事情的人最好情绪不要这么波动。

骚年，你看到了两个宰相都思考过的问题。

一是秦朝宰相[李斯](https://zhida.zhihu.com/search?content_id=495439364&content_type=Answer&match_order=1&q=%E6%9D%8E%E6%96%AF&zhida_source=entity)，他年轻时悟出了老鼠论，具体就是他看到厕所中的老鼠，环境差，整天没啥食物，听到一点点风吹草动就吓得四处乱窜，整日担惊受怕还吃不饱。而粮仓里的老鼠则不然，环境好，随时有粮食吃，也没有人和狗随时骚扰，过的悠然自得。

李斯就感叹，人其实和老鼠一个样，过得好不好，关键在于平台不在于实力。所以他就发奋读书，为了到更高的平台去。

二是北宋宰相[吕蒙正](https://zhida.zhihu.com/search?content_id=495439364&content_type=Answer&match_order=1&q=%E5%90%95%E8%92%99%E6%AD%A3&zhida_source=entity)，三次拜相。没中科举前，家境贫寒 受了不少白眼，后来他当宰相了，后人根据其经历，附会写出了[《寒窑赋》](https://zhida.zhihu.com/search?content_id=495439364&content_type=Answer&match_order=1&q=%E3%80%8A%E5%AF%92%E7%AA%91%E8%B5%8B%E3%80%8B&zhida_source=entity)打油诗，其中感叹:人道我贵，非我之能也，此乃时也、运也、命也。

汉初，[刘邦](https://zhida.zhihu.com/search?content_id=495439364&content_type=Answer&match_order=1&q=%E5%88%98%E9%82%A6&zhida_source=entity)，[萧何](https://zhida.zhihu.com/search?content_id=495439364&content_type=Answer&match_order=1&q=%E8%90%A7%E4%BD%95&zhida_source=entity)等汉朝集团里，一大半都是沛县的一般人出生，照样治国理政，开启汉唐世盛世，说明平台重要性。没有这个机遇，刘邦一辈子也就是地方一个地头蛇，[樊哙](https://zhida.zhihu.com/search?content_id=495439364&content_type=Answer&match_order=1&q=%E6%A8%8A%E5%93%99&zhida_source=entity)照样卖他的狗肉，[吕后](https://zhida.zhihu.com/search?content_id=495439364&content_type=Answer&match_order=1&q=%E5%90%95%E5%90%8E&zhida_source=entity)仍然种地。

所以，正如李斯感叹:人之贤不肖譬如鼠矣，在所自处耳。

正如文中感叹:时也，命也，运也。

当然，聪明不等于智慧，社会上混，光聪明不行，得有点智慧才行。

附上寒窑赋顺口溜，中年人读一读，应该感慨万千，博君一笑。

《寒窑赋》

青春美女，却招愚蠢之夫；俊秀郎君，反配粗丑之妇。蛟龙未遇，潜水于鱼鳖之间；君子失时，拱手于小人之下。衣服虽破，常存仪礼之容；面带忧愁，每抱怀安之量。时遭不遇，只宜安贫守份；心若不欺，必然扬眉吐气。初贫君子，天然骨骼生成；乍富小人，不脱贫寒肌体。

天不得时，日月无光；地不得时，草木不生；水不得时，风浪不平；人不得时，利运不通。注福注禄，命里已安排定，富贵谁不欲？人若不依根基八字，岂能为卿为相？

小时候跟个老爷子下棋从来没赢过。

不过我经常能在必败时憋出点歪招，出其不意地多挺几步，所以他不但不讨厌跟我这个臭棋篓子下棋，反而夸我聪明有“急智”。

我问他怎么才能赢，他说你不能光看自己的棋，要看我的棋，要琢磨我是怎么想的，如果有一步棋你看不出来什么意思，那八成是要输了。

我说您还真谦虚，还八成要输，我就没赢过。

他说那是因为你连我走的两成臭棋都没看出来。

后来我慢慢试着琢磨，从一两步到两三步，最后可以琢磨到四五步了，可还是赢不了，因为琢磨清楚的结果只是知道自己怎么输而已。

这下好了，不但赢不了，反而连那点“急智”都丢了。

我又问老爷子，您是不是藏了一手，为啥我怎么都琢磨不过您呢。

他给了我一本《橘中秘》，让我没事翻翻。

我像得到武林秘籍一样如饥似渴地研究起来，越研究越冷汗直流，原来上面写得明明白白的飞刀陷阱自己全中了，从开局自己就已经输了，所谓的聪明只不过是被人家当猴耍。

我问老爷子，有这宝贝您怎么不早点拿出来，是不是怕输？

他呵呵一笑，说早给你会看吗？

当你只能看一两步的时候，是绝不会相信输在开局的，你只会以为自己输在了一两手臭棋。

后来我研究了很多棋谱，发现[《橘中秘》](https://zhida.zhihu.com/search?content_id=495598230&content_type=Answer&match_order=1&q=%E3%80%8A%E6%A9%98%E4%B8%AD%E7%A7%98%E3%80%8B&zhida_source=entity)里面也有不少漏招，利用这些漏招偶尔也能赢几回了。

这可把我乐坏了，那段时间天天找老爷子下棋，风雨无阻。

后来我问老爷子，您下了这么多年棋，就没发现《橘中秘》里有漏招？

他说有就有呗，咱又不是职业的，你一点漏招没有，别人怎么赢？

人家一局赢不了，谁还陪你下？

我当时心里还想，你就吹吧，不知道就不知道，还装无所谓。

直到多年以后[象棋软件](https://zhida.zhihu.com/search?content_id=495598230&content_type=Answer&match_order=1&q=%E8%B1%A1%E6%A3%8B%E8%BD%AF%E4%BB%B6&zhida_source=entity)普及了，我也开始跟电脑下，下了几十盘一盘都赢不了。

不只是赢不了，连赢的边都碰不着。

在又输了一盘之后忽然有了一种深深的无力感，那一刻让我觉得象棋已经索然无味，从此删了软件，那之后也再没下过。

所以为什么有的人很“聪明”，可就是一事无成？

因为“聪明”也是有等级的。

残局的功夫在中局，中局的功夫在开局，开局的功夫在古今棋谱，而下棋的功夫不在棋盘之内，而在人生之中。

当你只能看到残局，人家中局的功夫才是“聪明”。

当你只看到胜负，人家人生的功夫才是“聪明”。

这叫什么？

这就叫[降维打击](https://zhida.zhihu.com/search?content_id=495598230&content_type=Answer&match_order=1&q=%E9%99%8D%E7%BB%B4%E6%89%93%E5%87%BB&zhida_source=entity)。

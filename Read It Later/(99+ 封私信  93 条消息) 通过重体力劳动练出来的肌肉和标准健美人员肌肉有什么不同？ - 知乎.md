# 通过重体力劳动练出来的肌肉和标准健美人员肌肉有什么不同？

**简单一点，用图说话吧。**

### **首先，是[肌群不均衡](https://zhida.zhihu.com/search?content_id=726568356&content_type=Answer&match_order=1&q=%E8%82%8C%E7%BE%A4%E4%B8%8D%E5%9D%87%E8%A1%A1&zhida_source=entity)。**

因为大多数体力劳动者都是重复性劳动，比如农民、挑山工、建筑工人，他们的固定劳动其实锻炼的肌肉是不同的，没有人会在几项工作之间频繁切换，这就让他们的肌肉发展不均衡。

例如，农民长期弯腰挥舞锄头、镰刀，所以三角肌、斜方肌、肱二头肌较为发达，但[胸肌](https://zhida.zhihu.com/search?content_id=726568356&content_type=Answer&match_order=1&q=%E8%83%B8%E8%82%8C&zhida_source=entity)、肱三头肌和[前臂肌群](https://zhida.zhihu.com/search?content_id=726568356&content_type=Answer&match_order=1&q=%E5%89%8D%E8%87%82%E8%82%8C%E7%BE%A4&zhida_source=entity)相对薄弱。

![[Read It Later/attachments/7c5ea81b4b3b1ead6dc69e43da423fbd_MD5.jpg]]

肱二头肌、三角肌强，肱三头肌、前臂弱。

![[Read It Later/attachments/cb5a22be3053d7dccfca271acff855e5_MD5.jpg]]

肩部和大臂肌肉强，胸部肌肉群较弱。

而搬运工、挑山工，是背部的斜方肌、背阔肌和腿部肌肉较为发达。

但手臂肌肉相对弱，臂围很细。

因为他们的工作大多是肩部来抗重物，而不是依靠手臂。

![[Read It Later/attachments/4c488183137dd8685f3683dcb3728a1e_MD5.jpg]]

发达的斜方肌和背阔肌，手臂很纤细

![[Read It Later/attachments/3dbdda0ce2422a40a00d53e52f173787_MD5.jpg]]

侧面能看出来胸背肌肉很好，大小臂肌肉相对弱

而在健美人员，会特别强化来练习四肢的肌肉。

看起来臂围特别粗大。包括不容易在劳动中用到的小臂肌肉。

> 实际上，臂围如果过大，反而不利于劳动，因为灵活性会下降的很厉害。

![[Read It Later/attachments/4ff81117c8085ff169add00df83a5462_MD5.jpg]]

健美人员的臂围

### 其次，整体是视觉感，肌肉不明显。

重体力劳动者大多收入并不高，他们的饮食偏向低蛋白、高碳水，所以哪怕体脂率不高，但肌肉线条并不是饱满鼓涨的感觉。

比如建筑工人体脂率同样很低，但摄入的蛋白不足，加上劳作的时间过长，肌肉看起来不明显。

整体视觉是“流畅”，而不是“壮硕”。

![[Read It Later/attachments/14e15ba6e97c5c4208f789532f19cab7_MD5.jpg]]

哪怕核心肌肉，依然如此。

比如因为经常在体前搬运东西，会让胸肌线条比较明显，但也不是“膨胀”的感觉。

![[Read It Later/attachments/5c598a96a46dbcc816ab4adbc6371ae8_MD5.jpg]]

虽然他们的肌肉比白领强很多。

但是，如果对比健美人员的肌肉，在视觉上依然差距明显。

![[Read It Later/attachments/b52d35e6f7f1acda64a7aded82502d38_MD5.jpg]]

健美人员的胸大肌

### 第三，肌肉随着年龄会相差较大。

大部分年轻的体力劳动者，会比年老的体力劳动者身体看起来状态好很多。

这是因为在繁重的劳动中，他们的肌肉也会收到损伤，一旦停止劳动会快速萎缩。

![[Read It Later/attachments/6635d749d40dc29f3136d98790f131ff_MD5.jpg]]

年轻的建筑工人

年轻时候，体力劳动者的核心肌肉会很明显。

因为重体力劳动很多持续握持、肩扛重物的动作。对锻炼到核心区域。

![[Read It Later/attachments/1f17791fb5c7a6bff20d4f55fde0ba4b_MD5.jpg]]

![[Read It Later/attachments/c5fda381404b0ff11c8e8348e61301c3_MD5.jpg]]

而随着年纪稍微上升——比如30岁以上，随着代谢和饮食习惯，像是小腹这样很难在劳动中用到的肌肉部位，容易囤积脂肪。

因此，工地周围的夜市上，40~50岁的工人，肚子都比较明显，虽然他们的力量依然很大。

![[Read It Later/attachments/2910b6dc8adaf6778499ed9110b0e1db_MD5.jpg]]

小腹明显的脂肪更多

**还有一类是民间锻炼的群体，并不是体力劳动者，他们的肌肉也和健身房有区别。**

比如公园里玩健身器材的大爷们。

通过保持较多的运动量，能让身体看起来很年轻，但因为没有健身房特定肌肉训练+[蛋白粉](https://zhida.zhihu.com/search?content_id=726568356&content_type=Answer&match_order=1&q=%E8%9B%8B%E7%99%BD%E7%B2%89&zhida_source=entity)的加持，所以肌肉也不是膨胀感，可以说人家的目标是“健康”而不是为了“形体”。

![[Read It Later/attachments/cf28525983be1c2d6de52b940a64f62b_MD5.jpg]]

不看头，身体仿佛30岁正常运动的年轻人

**此外，公园里面的健身器材，大多是耐用的固定型器械。**

这种器械更容易锻炼大块的躯体肌肉，提升整个身体的协调性，强化上肢和核心肌肉群。

健身房器械‌则可以通过孤立训练和固定轨迹刺激目标肌群，针对性训练肌肉。

所以，老人们训练的身材目标是“身体状态维持和年轻时相仿”，而不是肌肉的视觉感受。

![[Read It Later/attachments/0bfb21cc9701f7f6ee1595c10926f0a1_MD5.jpg]]

固定器材训练，会让背部和大臂肌肉群更明显

**还有一类劳动者因为营养摄入不足，或过度劳动，而显得身体比较消瘦、纤细。**

但是力量上并不弱，尤其是重复连续的劳动中，持久力很强。

比如很多拣货工、站立式生产线工人，都是这类身材。

![[Read It Later/attachments/8c2fec4c48dc63170640695214416324_MD5.jpg]]

又瘦又有力量的体力劳动者身材外形。

### **还有皮肤弹性问题。**

大部分重体力劳动者都是在太阳下劳作，对比健身房会让皮肤被紫外线照射较多。

这就体现为当年纪较大后，皮肤的弹性明显降低，松弛，尤其在褶皱较多的肋下、腹部。

![[Read It Later/attachments/6faa2238db241edfce71f8a86c34ac4f_MD5.jpg]]

哪怕肌肉强劲，但两肋皮肤松弛

而一些老人，从皮肤颜色与状态就能看出来，年轻时候并不是从事户外体力劳动，是年纪大了后才主动通过锻炼健身的，因此皮肤的弹性会更好。

![[Read It Later/attachments/23654dbe5e26f544edda1b6b33e39672_MD5.jpg]]

年轻时不需要在阳光下工作，会让皮肤状态更好

前年，我们实验室冰箱坏了，托关系弄了批新冰箱替换。

结果大楼电梯不给用！

怎么协商，就是不行。我也不知道管理员是不是脑子坏了。

  

30楼，你不给我用电梯，让我们抬上去？

后来我想了个办法，把冰箱抬到四楼去，脱离保安的视野，然后电梯到29楼，再抬进30楼实验室。

叫了几个研究生，大家轮流抬。

挑了个最小的冰箱，四个女生都抬不动，还得我自己上。

两男两女分别抬着四个角，上一层楼，休息几分钟，换人。

千辛万苦终于送进了实验室，大家都快趴下了。

  

下面还有两个大冰箱，比人都高。

更麻烦的是，冰箱体积大了，上楼梯时候只能两个人搬。

有个学生，一米九的个子，酷爱健身，体壮如牛。

也就我们俩一起能抬得起来。但想搬上四楼完全不现实。

我准备打电话让主任来解决，主任表示他也没办法，等下手术台再说。

大家在楼下面面相觑。

  

有个女孩子说她知道个搬家公司。

大家一致摇头——这么大的冰箱，搬家公司又不是大力神，怎么弄上去？

女孩子坚持要打个电话，一问价格，来一趟50，外加20块钱一层楼。

那就这么愉快决定了。

过来一辆小面包车，下来一个农民工和一个司机。

我一看就两个人，咋搬啊？

结果那个农民工用绳子把冰箱一捆，背在肩膀上，直接上楼了。

我跟在后面，真怕他一跟头栽下来，心惊肉跳。

结果人家脚步轻快，四层楼上去都不怎么喘气。

进实验室时候两手一翻，随随便便就放地上了，跟放个纸盒子似的。

一共不到200块钱，十几分钟，收工了。

我赶紧递烟，说休息一会吧，人家咧嘴一笑，压根不当回事。

  

抽烟时候仔细打量了下这位农民工。

年龄少说也40了，个子不高，看起来瘦瘦小小，要是发生冲突我估计我能打十个那种。

事实上，恐怕他一只手就能拎小鸡一样，把我扔到二十米外。

  

爱健身的壮小伙就在边上偷偷瞄人家肌肉，瞄一眼，摸一下自己，一脸黑人问号。

我主要是在关注他乌黑浓密的头发，总是想开口问怎么生发的。

一根烟没抽完，农民工大哥估计给我们俩看得发毛，急忙忙溜了。

### IT历史连载45-中国学习机之90年代的电脑学习机的那些事

![[Read It Later/attachments/88134ec44b2145c3ab3205ba82df59da_MD5.jpg]]

**1987年：**广东中山[小霸王电子工业公司](https://zhida.zhihu.com/search?content_id=217263449&content_type=Article&match_order=1&q=%E5%B0%8F%E9%9C%B8%E7%8E%8B%E7%94%B5%E5%AD%90%E5%B7%A5%E4%B8%9A%E5%85%AC%E5%8F%B8&zhida_source=entity)成立。

**1986年：**[电子工业部计算机与信息局](https://link.zhihu.com/?target=https%3A//rpc.huijiwiki.com/index.php%3Ftitle%3D%25E7%2594%25B5%25E5%25AD%2590%25E5%25B7%25A5%25E4%25B8%259A%25E9%2583%25A8%25E8%25AE%25A1%25E7%25AE%2597%25E6%259C%25BA%25E4%25B8%258E%25E4%25BF%25A1%25E6%2581%25AF%25E5%25B1%2580%26action%3Dedit%26redlink%3D1)组织，清华大学主持设计，[电子部六所](https://link.zhihu.com/?target=https%3A//rpc.huijiwiki.com/index.php%3Ftitle%3D%25E7%2594%25B5%25E5%25AD%2590%25E9%2583%25A8%25E5%2585%25AD%25E6%2589%2580%26action%3Dedit%26redlink%3D1)、国营734厂、[陕西省计算机厂](https://link.zhihu.com/?target=https%3A//rpc.huijiwiki.com/index.php%3Ftitle%3D%25E9%2599%2595%25E8%25A5%25BF%25E7%259C%2581%25E8%25AE%25A1%25E7%25AE%2597%25E6%259C%25BA%25E5%258E%2582%26action%3Dedit%26redlink%3D1)以及[华明计算机有限公司](https://link.zhihu.com/?target=https%3A//rpc.huijiwiki.com/index.php%3Ftitle%3D%25E5%258D%258E%25E6%2598%258E%25E8%25AE%25A1%25E7%25AE%2597%25E6%259C%25BA%25E6%259C%2589%25E9%2599%2590%25E5%2585%25AC%25E5%258F%25B8%26action%3Dedit%26redlink%3D1)推出**中国第一台学习机**\-**中华学习机CEC-I（China Education Computer）**。基于[Apple II](https://zhida.zhihu.com/search?content_id=217263449&content_type=Article&match_order=1&q=Apple+II&zhida_source=entity)[电路图](https://www.zhihu.com/search?q=%E7%94%B5%E8%B7%AF%E5%9B%BE&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B)架构，1977-1987年的上万种软件，从【功能集成成本控制】和【内置中文系统化】自研的兼容机。具备AppleSoft BASIC、[CEC LOGO](https://zhida.zhihu.com/search?content_id=217263449&content_type=Article&match_order=1&q=CEC+LOGO&zhida_source=entity)、[ASM汇编语言](https://zhida.zhihu.com/search?content_id=217263449&content_type=Article&match_order=1&q=ASM%E6%B1%87%E7%BC%96%E8%AF%AD%E8%A8%80&zhida_source=entity)的开机即用能力。配用录音机和普通电视机，可实现基本系统。

**1987年：**CEC-I型中华学习机通过生产定型鉴定，正式投产。

**1987年4月20日：**国家科委、国家教委、电子工业部、中国科协等在京联合举办了**中国第一次中华学习机系列展示会**，把中华学习机推上了历史舞台。

![[Read It Later/attachments/f0938da7a02b673c1ca01039898cba28_MD5.jpg]]

![[Read It Later/attachments/5306632f58ff97c2866385f15b8ced13_MD5.jpg]]

**1988年10月：**中国教育电子公司成立（隶属电子工业部），负责对中华学习机的硬件和软件的开发、生产和推广工作。

**1988年11月8日：**机械电子工业部主办的《计算机信息报》增版刊登了**中国中华学习机普及协会成立**，中共中央政治局委员、国务委员、国家教委主任李铁映同志撰写文章**《大力发展中华学习机》。**李铁映指出：**十一届三中全会以来，我国出现一片学习热潮，这是中华民族振兴的希望，学习用计算机，我们取名“中华学习机”，它的出现，标志着学习手段、学习工具的进化，对于提高国民的文化素质，改善落后状况将会起重要作用**

**1989年1月：**

![[Read It Later/attachments/7a544e76966f4f206c603120e35b4408_MD5.jpg]]

**1990年：**全国有400万多台中华学习机投入应用，销量最大的是CEC-I型号

**1990年：**北京四达技术开发中心、四达智能设备厂研制了**[普里奇声像教学系统](https://zhuanlan.zhihu.com/p/82183761)**

![[Read It Later/attachments/a7adad1704d9893c6fef40a70909d4ec_MD5.jpg]]

**1990年：**中国电子器件公司深圳公司(NEDC)制造了**中国第一台以任天堂键盘套装为蓝本设计的科特电脑学习机**FCS-90，零售价675元。

![[Read It Later/attachments/9b60517ba1dae7a773b8289e389eb1f9_MD5.jpg]]

![[Read It Later/attachments/f4ab3d2537face09bcefd2a5786e97bb_MD5.jpg]]

**1990年：**国内引进港台生产的BIT79电脑学习机，外形类似APPLE II电脑，内置BASIC编程语言，可插任天堂游戏卡。

![[Read It Later/attachments/3421bb4b5e3bd7337d8476cf63f54e70_MD5.jpg]]

**1992年：**中国电脑学习机进入爆发期。

**1992年：**成立一年的**[裕兴公司](https://zhida.zhihu.com/search?content_id=217263449&content_type=Article&match_order=1&q=%E8%A3%95%E5%85%B4%E5%85%AC%E5%8F%B8&zhida_source=entity)**推出配套家用游戏机的电脑键盘和学习卡YX-2

![[Read It Later/attachments/d329060b96576bfc507f0902c83b2cdb_MD5.jpg]]

**1992年：**广东佛山市的升发电子厂发售了一款名为[GMT-92](https://zhida.zhihu.com/search?content_id=217263449&content_type=Article&match_order=1&q=GMT-92&zhida_source=entity)的中文电脑学习机

![[Read It Later/attachments/a90cbb1405305ad2d21a10e0a8c5e47d_MD5.jpg]]

**1992年：**小霸王转型电脑学习机，20万元买断流行的[五笔输入法](https://zhida.zhihu.com/search?content_id=217263449&content_type=Article&match_order=1&q=%E4%BA%94%E7%AC%94%E8%BE%93%E5%85%A5%E6%B3%95&zhida_source=entity)

![[Read It Later/attachments/b35f1fbfd5203832b30a7e61e772d007_MD5.jpg]]

![[Read It Later/attachments/091e98e65362f0d484b939e6ba4c27af_MD5.jpg]]

![[Read It Later/attachments/64e24d2e2662391197bdf286d43b7da4_MD5.jpg]]

**1993年：**小霸王研发第二代学习机，并邀请成龙拍摄《小霸王望子成龙篇》广告，广告语“**同是天下父母心，望子成龙小霸王**”的广告。代表型号为SB-486、SB-486B、SB-486D,其中SB-486D采用流行的电脑101键盘、打印机接口、词组联想、浮点BASIC语言和五笔练习。

**1994年1月：**裕兴推出YX-4、YX-5分体式键盘学习机，采用流行的101键盘，可以在286、386、486电脑上使用

![[Read It Later/attachments/ed9b55a726c1cc5c3a8e0abcc514aaac_MD5.jpg]]

**1994年3月：**五笔输入法发明人[王永明教授](https://zhida.zhihu.com/search?content_id=217263449&content_type=Article&match_order=1&q=%E7%8E%8B%E6%B0%B8%E6%98%8E%E6%95%99%E6%8E%88&zhida_source=entity)给裕兴题词“**裕兴普及型电脑学习机，使用标准微机原装键盘，这是一个突破，该机功能强，易学易用，是推广五笔字型、在青少年中普及电脑的上乘之作。**”

**1994年：**小霸王在中央电视台黄金时段播放家喻户晓的《拍手歌》广告“**你拍一，我拍一，小霸王出了学习机**”，该广告获中央电视台1994年首届电视广告大奖。

![[Read It Later/attachments/052a0f71ab85ebe7db3f8779861c4959_MD5.jpg]]

![[Read It Later/attachments/8d57fa124ea8fca7064cd87acc9bd55e_MD5.jpg]]

**1994年：**国内兴起学英语热潮，小霸王研发《英语词霸》学习卡，通过国家教委鉴定。学习卡含有初中、高中以及大学的英语单词、历届中高考试题、单词记忆和英语歌曲欣赏等内容

![[Read It Later/attachments/bb3f643a623ebb7db649fa93ab5eb6e0_MD5.jpg]]

**1994年：**天津新星电子公司推出一款磁盘式中英文电脑学习机，目前**国内最早的内置软驱的学习机**。

![[Read It Later/attachments/2517abf858753aed1c19ae526263fcad_MD5.jpg]]

![[Read It Later/attachments/1e1d4c6be054fe9fa3297f8e55bd769d_MD5.jpg]]

**1994年：**中国电脑学习机市场上的3个活动：

**一、中国企业家协会暨中国企业信息交流中心的94年全国市场产品竞争力调查评价：**

- **“心目中的理想品牌”前三名：小霸王（79.194%）**、中华（12.100%）和小博士（3.206%），三个品牌占总数的94.5%；
- **“实际购买品牌”前三名：小霸王（74.615%）**、中华（11.117%）和金字塔（4.785%），三个品牌占总数90.517%；
- **“1995年购物首选品牌”前三名：小霸王（79.693%）**、中华（11.560%）和小博士（3.153%），三个品牌占总数的94,406%。  
	**二、1994年下半年，中国消费者协会购买12种品牌的学习机的比较**
- **硬件：金字塔PEC-9388、裕兴YX-4C、GMT-92、和声HS2188A领先**
![[Read It Later/attachments/282ef60c9bd1b8bad0b6fe75d0762526_MD5.jpg]]

- **学习卡软件功能：**
![[Read It Later/attachments/01a63d99d3d20883aa588a1754a33df8_MD5.jpg]]

- **小霸王、裕兴、金字塔学习机被推荐为消费者选购的“优选产品”**  
	**三、1994年11月底：《中国少年报》首届全国家用电脑学习机用户调查：**
- **小霸王中英文电脑学习机的市场占有率为57%**
- **打算选购小霸王的用户占71%**
- **电脑学习机的满意度为84%**
- **小霸王被评为最受欢迎品牌、质量性能金奖和售后服务优秀奖；**
- **小教授获质量性能优秀奖；**
- **金字塔和王中王被评为市场知名品牌。**

**1995年1月：**裕兴推出YX-686一体机，很快在市场上脱销。3月，推出YX-886A（690元,内置3.5寸软驱扩展槽）和YX-886B（1190元，内置3.5寸软驱）

![[Read It Later/attachments/802387d5dbeb59d569b483496b7bdc16_MD5.jpg]]

**1995年：**2月《电脑爱好者》刊登《学习机与微机握手》，介绍北京裕兴机电研究所开发的学习机上适用的“高级中文文字处理软件”《裕兴WPS》。

**1995年3月：**3月《家庭电子》刊登《**电脑学习机热是否该“降温”**》“**一些家长误信广告上的片面宣传，把购买电脑学习机作为家庭教育的重要内容，殊不知电脑学习机无非是原有游戏机的改进，其主要功能，仍是一种娱乐工具。**”

**1995年：**新星推出16位学习机FDC-2000：世嘉MD 3.5英寸软驱、四个游戏手柄和1380元的震撼价格（1995年全国城镇居民人均年可支配收入4283元）

![[Read It Later/attachments/44ceee75d0a649f1e0e780ec3c71e2ad_MD5.jpg]]

![[Read It Later/attachments/eaddb25076b4a217e8f6c043c23d73f6_MD5.jpg]]

**1995年9月18日：**离开小霸王的**段永平**创立**[步步高公司](https://zhida.zhihu.com/search?content_id=217263449&content_type=Article&match_order=1&q=%E6%AD%A5%E6%AD%A5%E9%AB%98%E5%85%AC%E5%8F%B8&zhida_source=entity)**

**1995年6-11月：《电脑爱好者》类型刊发电脑学习机纵横谈系列5篇文章。**

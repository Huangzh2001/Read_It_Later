相信熟悉数码圈的你已经听说了，华为推出了新一代轻薄本 MateBook Pro，和折叠屏笔记本 MateBook Fold，就是我面前这两位，他们是首批搭载华为自家鸿蒙系统的PC，不是 Windows，不是 Linux，不是安卓，而是鸿蒙PC，并且他俩还使用了一颗前所未有的处理器 麒麟X90，这是一颗专为PC打造的麒麟芯片，这样听起来，是不是感觉这两款产品还挺有里程碑意义的呢？哎 今天我们就要来好好测一测，这个麒麟X90，华为的PC芯片，他到底是何方神圣？性能如何？功耗如何？相当于苹果和英特尔哪一代产品?以及我们也要来好好看一下，这鸿蒙PC到底能做些什么？给他开发软件的体验 到底怎么样，今天的节目干货满满，一定要给我们点赞 收藏 转发，那我们就赶紧开始吧！这台就是起售价 7999 的 MateBook Pro 了，看起来这个面孔就很熟悉啊，它用的就是之前 MateBook X Pro 的模具，只是换了个处理器，换了个系统，还有其他一些小变化，单从用料的角度这个机器卖 7999 算是很可以了，因为MateBook X Pro本来就是上万的旗舰轻薄本模具，980g的重量里实现了40W 的性能释放，与此同时还保持顶级的做工，想了解这个模具的话，推荐各位去看一下笔吧的视频，那我们就不赘述了，直接开拆，卸下底部螺丝，包括藏在脚垫里的两颗，就可以把D壳拆下来了，这个就是 MateBook Pro 的内部设计。

最显眼的还是中间这一大块均热板，我们断电后卸下散热螺丝，取下这块均热板，就可以看到主板的真容了，这个机器的主板设计有点想法的，它是中间一个矩形主板+左右两侧小板的分离结构，接着往下拆掉风扇，再拆掉固态，这个SSD底下就藏着处理器的板载内存，再拆掉转轴处的保护罩，你就会发现主板上大量使用了BTB连接，顶上是BTB屏线，左右两侧是和小板连接的排线，再加上底下的排线，可以说整个主板被排线座子围了一圈啊，有种万物聚拢到中间的感觉，这就是拆下来的 MateBook Pro 主板了，中间这颗就是麒麟X90处理器，意料之外地，作为一颗自研 ARM SoC，他并没有像苹果M系列 高通X Elite 英特尔Lunar Lake，或者手机那样使用集成度和能效都更优的 PMIC 供电，而是继续跟传统X86芯片一样用了 VRM 供电，你可以看到主板上的各种电感和 MOSFET，我的理解可能是为了方便沿用上代的模具，上代英特尔 Meteor Lake 的机器就是 VRM 供电，希望这不会太影响到功耗，那么是时候来好好聊一下这颗麒麟X90芯片了，看到它第一眼你就会发现，它的核心面积非常之大，达到了 208 平方毫米，这比苹果M系列 AMD 7840H 高通X Elite都要大得多，仅次于 HX370，实际上相比手机的麒麟9020，这颗给PC设计的X90，面积大了48%，这还是在X90没有集成5G基带的情况下，这么大一个SoC。

面积到底都用在哪儿了呢？其实主要就是CPU、GPU和NPU，X90的CPU部分由四颗超大核、四颗大核和两颗中核组成，每一种核心都支持超线程，总共10核20线程，超大核基于9010的超大核改进而来，每核配备1M L2缓存，最高2.32GHz频率，大核也是基于9010的超大核改来但略有缩水，面积要稍微小一些，L2缓存依然是1M，最高2.01GHz频率，所以与其说超大核跟大核，不如说是大一点的超大核跟小一点的超大核，两颗中核基于9010的大核，但是把L2缓存砍到了512K，当成小核来用了，整个CPU的中间还提供了16M的L3缓存，由所有核心共享，这个CPU规模算是相当庞大了，只是频率依然跑得比较低，正上方是麒麟X90的GPU——马良916，和麒麟9010的马良910同一代架构，但规模大了不少，从4CU加到了6CU，最高频率950MHz，旁边这一小块是NPU，比手机上大一倍的规模，最后还提供了8M SLC，作为一颗PC芯片，麒麟X90理所当然地和苹果、英特尔、AMD一样，支持128bit内存，同频比手机的 64bit 内存带宽大一倍，具体来说 MateBook Pro 配备了 LPDDR5 6400 双通道内存，所以CPU性能应该会比同架构的手机来得更好，实测结果也是印证了这一点，这次我们把行业标准工具 SPEC 2017 搬上了鸿蒙PC，除Fortran以外的测项都可以跑通，那我们就剔除以往的 Fortran 子项，来看一下CPU单核。

X90这颗超大核比同频的9010要再强一些，但不如9020的超大核，X90的大核性能稍差一些，而中核由于只有512K缓存，性能其实打不过同源的9010大核，不过当小核用是绰绰有余了，那么他这个超大核的单核性能，放在PC里大概是什么水平呢？差不多相当于英特尔 i7 8565U 的单核，Skylake 时期的单核，也跟苹果A12Z的单核接近，没办法，2.3GHz的频率实在是太低了，核心做得再大也很难跑出性能来，能效上说，鸿蒙PC我们只能测主板功耗，测不到封装功耗，PC由于外围功耗比手机高得多，再加上麒麟X90用了 VRM 供电，板耗肯定和手机没法比，我们来对比其它的PC好了，其实吧，看单核能效的话，麒麟X90倒是还行，虽然单核性能差，但好在功耗不高，和优等生苹果可能没法比，我们可以和 AMD 前两年的 Zen4 4nm CPU 8840HS，也就是 7840HS 来比一比，正好他俩都用的VRM供电，看起来，X90平台的单核性能跟功耗，应该和 3GHz下的 8840HS 轻薄本差不多，两者的单核能效还挺接近的，当然x86处理器胜在能跑高频，满血 5GHz 的 Zen4 不用想都知道有多强，但如果不求那部分爆发的 boost 性能，放在轻薄本上用的话呢，X90的单核论能效还不算太落后，就和前两年的x86平台差不多，那么俗话说，单核不够，多核来凑，虽然缺了那部分爆发性能，但至少麒麟X90很愿意堆料，CPU核心堆得足够多，再加上超线程帮忙。

他的多核性能到底怎么样呢？这多核测试我们就没办法像其他PC那样，测 Geekbench 或者 Cinebench 了，因为这几个跑分软件都没有登陆鸿蒙系统，并且闭源软件我们没有源码的话是没法移植过来的，好在我们的工程师想办法移植了几个开源的软件到鸿蒙上，也算是能测出一些关键的性能表现了，一起来看看好了，首先我们跑了 ffmpeg 的 X264 CPU 视频编码，这个主要是考验多核整数性能，我们根据1080P转码用时计算了性能倍率，哎 你还别说，这麒麟X90的CPU多核，还真不错啊！在4+4+2这种疯狂的堆核策略下，麒麟X90可以打赢只有4个超大核+4个中核的M1、M2，甚至M3和英特尔 Lunar Lake，是不是有点没想到啊？结合功耗来看，在有规模优势的情况下，麒麟X90的多核能效其实也和 Lunar Lake 差不多，当然跟 Lunar Lake 比多核可能还是有点赖皮的，等于是拿X90的长板打 Lunar Lake 的短板，但确实它的多核能效算是还不错的，如果是和英特尔那边一样堆规模的 Meteor Lake 比，X90这个多核性能依然有差距，我们再来跑一个 7-zip 的sdk测试，和市面上的7z自带的基准测试不一样，我们编译的这个套件不仅涵盖了LZMA等压缩算法，还包括AES、CRC、SHA等很多的，加密、哈希相关的算法测试，他其实是比较综合的，算是一个大的整数测试套件了，那我们测出来的结果。

麒麟X90依然挺不错的，性能再次打赢了苹果M3和英特尔258V，它的多核表现其实会更接近规模大一点的M1 Pro，尽管和 Matebook X Pro 的 U7-155H 还差了一截性能，但结合功耗的话，这个能效还是完全不输给英特尔的，我们再来跑几个浮点测试看看，像是SPECspeed里的三个多核子项，619比较受内存带宽制约，麒麟X90在这里好像没办法访问到全部的内存带宽，一下子就失去优势了，但638和644这两项，X90的表现又挺不错的，性能打赢M3，跟英特尔比也是不遑多让，如果比功耗的话可能不像苹果那么好看，但和英特尔打还是有戏的，总体来说，麒麟X90的CPU单核性能比较菜，但能效上勉强合格，而多核则是给了我们不小的惊喜，依靠堆核大法砸出了还不错的性能，多核能效也是完全不输给英特尔的 Meteor Lake 和 Lunar Lake，当然硬要说的话，它肯定打不过最新的 Arrow Lake-H 和苹果M4，但这毕竟是全链路自主开发的处理器，我本来就没有把期待值放得很高，倒不如说X90的CPU能达到现在这个性能，已经远远超过很多人的预期了，你说是不是啊，这CPU我觉得还是挺靠谱的，那GPU的性能又怎么样呢？哎 GPU这玩意就很难测了，我们本来计划，最好是移植一个原生的图形负载到鸿蒙系统上，比如移植一个游戏，我们先试着移植了 id Software 经典开源游戏 DOOM 3。

甚至游戏都已经能进到主菜单了，但很可惜没能成功载入地图，因为鸿蒙对程序的栈内存限制非常严格，而 DOOM 3 恰好用了很多需要大栈空间的写法，为了进主菜单，我们已经改了不少地方，比如它原本为了性能把大量内存分配放在了栈上，我们只能一个个改成堆分配，才勉强跑起来，折腾了好几天，本来我们已经放弃了，结果你猜怎么着？更新了一版系统，居然就能进游戏了！哇 这你想得到吗？我感觉应该是内存管理上有改动，不过 哪怕能进游戏，我们发现也没法对比测试性能，因为其他平台的DOOM 3都是有编译器优化的，而我们移植的鸿蒙版，一旦开编译器优化又会直接爆掉，没法一直玩下去，所以尽管费了好大的劲才跑起来游戏，我们也只能放弃了，原生移植行不通，那还有一个办法能跑GPU，就是WebGL，用浏览器来跑一些跨平台的测试，其实业界也有像毒蘑菇，或者 Aquarium 这样的特性或者 Drawcall 测试，但我们这次准备用一个更合理，更接近实际工况的东西来测GPU，而且我说出来你绝对拍手称快，什么东西呢，就是 WebGL 版的 Minecraft，打上光影！首先，MC的光影和大多数光栅化游戏接近，像延迟渲染、SSAO、SSR、次表面散射这些都有，相比毒蘑菇那种通过跑三角函数，只压榨硬件SFU单元的负载也会更有参考性，其次 WebGL 是 OpenGL ES 的子集，用 Chromium 内核浏览器跑的话。

基本能直接对应到底层图形接口，性能也很接近原生，再加上它几乎是 GPU 满载运行，瓶颈主要在 GPU，CPU 的损耗影响不大，最关键的一点是——在鸿蒙系统上，正常的 JIT 被限制了，很多模拟器类的跑法都不行，但浏览器本身的 JS 引擎就是靠 JIT 的，所以我们用 WebGL，就相当于“借壳”让它帮我们完成 JIT，这可能是目前鸿蒙上最接近原生性能的方式了，不过 拿WebGL版MC来评测也有一些限制，首先 我们没法 对比高通机型，因为高通官方的 GPU 驱动为了追求性能做了很多的“优化工作”，他是没法跑通这版MC的，这也是为什么会有社区给他做 Turnip 开源驱动这种东西，其次，在 Windows、macOS 和 Linux 的 Chromium 浏览器里跑 WebGL，需要经过谷歌的ANGLE转译，这是存在性能损耗的，而安卓和鸿蒙上就像我前面说的，可以直接对应底层接口，跑到 OpenGL ES 上，所以真正能直接和X90对比GPU的，就是手机上的麒麟和发哥的天玑平台，不过PC端我也把转译的性能跑了下，我们前面在dieshot上看到，麒麟X90这个马良916 GPU规模增加到了6CU，但实际到了游戏里，它的性能好像也没比9020的GPU强多少，这是因为它基于9010上的老架构，软件效率差了新款GPU很多，你要知道9020比9010的GPU提升是很大的，X90的GPU基本上是和天玑9000差不多的性能。

哪怕和转译后的苹果M1、英特尔155H比，都差了挺远的，和原生的天玑9400比，差距就非常大了，应该说，这个GPU算是整个SoC上比较短的一块板了，第一代嘛 可以理解，我还是更期待以后能用9020上的新架构来做PC的GPU，不过话说回来，MC光影应该是我测这么久鸿蒙，玩到的第一个有点图形压力的游戏了啊，这个GPU也是不容易，总算有机会打一场酣畅淋漓的架了，如果要从应用商店找游戏，那正经一点的，可能目前只有苍翼：混沌效应、三国杀和蔚蓝档案了，它这个GPU强一点弱一点，在BA这种负载里，你猜能有啥影响呢？一点影响都没有，还是等等未来看看能不能有更多游戏登陆鸿蒙PC吧，好了 硬件性能能效部分分析完了，干货还是挺多的吧？我觉得这次的麒麟X90作为自研架构PC芯片的起点，已经算是挺ok的了，至少CPU比我预期是要好不少的，这得感谢芯片团队不惜成本地堆料，塞这么多核心进去，让它的多核表现也算是能跟得上时代了，不过这台PC更让大家好奇的，可能还是它的软件，它的鸿蒙系统，这个我们已经用了大半个月，其中大多数时间是在给他开发软件，所以今天，我就从消费者和开发者这两个角度来聊一聊鸿蒙PC，首先大家肯定很好奇，这个软硬件都是自己做的，是不是意味着续航会很好？能不能做到苹果那样优秀的办公续航呢？我们决定基于之前极客湾PC续航脚本的标准。
